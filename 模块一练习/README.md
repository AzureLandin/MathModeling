# 数学建模队员分配问题：最终整理

本目录整理了问题1至问题4的复算脚本、原始附件副本、参考数据、模型结果和完整报告。所有脚本只读取本目录中的 `data/raw`，不修改原始文件。

## 目录结构

```text
最终整理/
├─ coding/                  # 问题1至4脚本及统一入口
├─ data/
│  ├─ raw/                 # 题目与原始附件副本
│  └─ processed/           # 展平后的参考数据及问题1/2中间数据
├─ results/                # 问题2至4计算结果
└─ reports/                # 问题1至4报告与计算结果
```

## 一键复算

在 `最终整理/coding` 目录运行：

```powershell
E:\conda\python.exe run_all.py
```

运行顺序：

1. `prepare_reference_data.py`：整理附件1、附件2和附件3统计；
2. `q1_analysis.py`：计算指导效率、AHP综合得分和I至IV级；
3. `q2_analysis.py`：归并研究方向并运行随机森林；
4. `q3_allocation.py`：计算百分位配额、选队次序和175次轮转位序；
5. `q4_matching.py`：计算教师--队伍匹配并输出完整分配方案。

## 最终口径

- 问题1采用“指导效率 + 累计获奖成果”模型，权重为 `1/3 : 2/3`；
- 奖项权重为国一0.6049、国二0.2801、省一0.0693、省二0.0458；
- 问题2研究方向归并为5类；
- 问题3采用 `A:[7,10]、B:[5,7]、C:[3,4]`，最终配额分布为2人10队、9人7队、10人5队、14人3队；
- 问题4严格按照问题3正确重建的175次轮转位序进行选择。

## 口径说明

`已完成` 文件夹中的前三问报告存在少量历史文字不一致，例如问题3削减过程一处误写“2号削到8队”，但最终表、配额汇总和175总量均要求2号与7号各10队。本整理以能够通过约束验证的最终结果表为准，并由脚本重新生成完整175次位序。

问题1的建模报告正文也混有旧版累计时间口径和新版效率口径的段落；本整理的复算脚本以 `已完成/计算结果_问题1.md` 中的新版效率公式和得分表为准。
