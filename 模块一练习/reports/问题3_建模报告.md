# 问题3：基于教师个人因素的建模队分配规则

## 一、问题重述

某校共有35名指导教师，本年度需将175支建模队分配给若干名指导教师。每队必须且只能由一名教师指导，每名参与指导的教师至少分配3队、至多分配10队。要求：

1. 对竞赛指导水平较高的教师**多分配队伍**并**优先分配**，对指导效果较差的教师**少分配队伍**；
2. 根据指导教师的**个人因素**（性别、学位、研究方向、职称等）制定分配规则；
3. 明确输出：各教师的**指导队数**、**选队次序**、**分配次序**。

> **前置问题衔接**：问题1通过AHP模型给出了每位教师的综合得分$S_i$；问题2通过随机森林回归和统计检验得到了四项个人因素的重要性排序（职称 > 研究方向 > 学位 > 性别），并确认了"职称效应已充分体现在$S_i$中"的结论。问题3的分配规则完全建立在$S_i$之上，个人因素通过$S_i$间接作用于分配结果。

---

## 二、规则设计原则与模型假设

### 2.1 设计原则

1. **单向性**：规则是自上而下的"校方指定"逻辑，不引入教师或队伍的双向意愿，完全基于可观测的客观信息进行分配。
2. **确定性**：任何给定输入（35名教师的$S_i$值）产生唯一确定的输出。
3. **硬约束优先**：先保证$3 \le q_i \le 10$且$\sum q_i = 175$成立，再在可行空间内实现优劣区分。
4. **得分主导**：分配差异的核心驱动变量是问题1的综合得分$S_i$，个人因素不重复加权。

### 2.2 模型假设

1. 问题1给出的综合得分$S_i$能够有效衡量第$i$名教师的竞赛指导水平。
2. 所有35名教师均参与本年度指导工作，无人退出。
3. Q3阶段175支建模队视为同质个体（队伍质量差异在问题4中另行考虑）。
4. 选队过程是顺序性的（教师按序从"未分配队伍池"中做选择），不存在补选或交换机制。

## 四、模型建立：三模块分配规则

### 4.1 模块一：指导队数规则

#### 4.1.1 百分位排位

将35名教师按$S_i$降序排列，秩次为$R_i$（$R=1$为最高分），则百分位排位：

$$P_i = \frac{M - R_i}{M - 1} \times 100, \quad P_i \in [0, 100]$$

#### 4.1.2 配额区间划分

按$P_i$将教师分为三组，每组对应一个配额区间：

| 组别 | 条件 | 配额区间 $[q_{\min}, q_{\max}]$ |
|:----:|:----:|:-----------------------------:|
| $G_A$（高优组） | $P_i \ge 70$ | $[7, 10]$ |
| $G_B$（中坚组） | $40 \le P_i < 70$ | $[5, 7]$ |
| $G_C$（基础组） | $P_i < 40$ | $[3, 4]$ |

**可行性验证**：设三组人数分别为$n_A, n_B, n_C$，则理论最小配额$\sum n_k \cdot q_{\min}^{(k)} \le 175$是规则可执行的充要条件。经验算，$11 \times 7 + 10 \times 5 + 14 \times 3 = 169 \le 175$，可行。

#### 4.1.3 连续配额映射

各组内按百分位线性插值得到连续配额：

$$q_i^{(0)} = \begin{cases}
7 + 3 \times \dfrac{P_i - 70}{30}, & P_i \ge 70 \\[10pt]
5 + 2 \times \dfrac{P_i - 40}{30}, & 40 \le P_i < 70 \\[10pt]
3 + 1 \times \dfrac{P_i}{40}, & P_i < 40
\end{cases}$$

#### 4.1.4 取整与总量修正

整数化：$q_i = \operatorname{clamp}(\operatorname{round}(q_i^{(0)}),\; q_{\min}, q_{\max})$

计算$Q = \sum q_i$，若$Q \neq 175$则执行修正：

- **$Q > 175$**：按$S_i$升序，对$q_i > q_{\min}$的教师逐人削减1队，直至$Q = 175$
- **$Q < 175$**：按$S_i$降序，对$q_i < q_{\max}$的教师逐人增加1队，直至$Q = 175$

### 4.2 模块二：选队次序规则

选队次序序列$\mathcal{V}$由全体教师按三层全序排序：

$$\text{排序键：} \quad (-S_i,\; -T_i,\; \text{teacher\_id})$$

即：得分高者优先 → 同分者年资深者优先 → 仍同分者序号小者优先。

### 4.3 模块三：分配次序规则

采用**多轮次轮转配给**机制，分为两轮：

**第一轮（保底轮）**：按$\mathcal{V}$依次遍历，每人每次选择1支队，循环3次。消耗队伍数 $3 \times 35 = 105$。

**第二轮（补充轮）**：Round-Robin 方式，按$\mathcal{V}$反复遍历。每次遍历中，每位未满额教师再获1队选择权，直至175支队全部分配完毕或所有教师达到各自配额。

等价于：$T_{(1)}$选3队 → $T_{(2)}$选3队 → … → $T_{(35)}$选3队 → $T_{(1)}$选1队 → $T_{(2)}$选1队 → … → 循环至175队耗尽。

## 六、结果分析

### 6.1 配额梯度的合理性

A级与C级的人均配额比为$7.55 : 3.00 \approx 2.5:1$，形成了清晰的梯度结构。A级教师以31%的人数承担了47%的指导任务，对"指导水平高者多分配"的题目要求给出了定量回应。B级教师均分5.0（恰好为整体均值），扮演了配额填充的中坚角色。

### 6.2 修正算法的有效性

取整后202队→177队→175队的修正路径中，7号教师（$S=85.72$）和2号教师（$S=77.10$）始终保留$q=10$的最高配额，体现了修正算法"低分优先受损"的设计意图。所有教师的最终配额均未跌破自身组别的$q_{\min}$，规则内部的组别划分与修正逻辑自洽。

### 6.3 选队次序与公平性的权衡

选队次序完全由$S_i$决定，最高分教师7号在每一轮补充中都是第1个出手（如pick_index 106/127/...），最低分教师3号在每一轮都是最后一个出手（pick_index 35/70/105）。多轮轮转机制避免了"第一名一次选完10队"的局面——第一轮保底使得末尾教师在前105个位序中也有3次机会，而非在所有教师满额后才被动捡剩。

### 6.4 与问题2结论的一致性

问题2得出的因素重要性排序为**职称 > 研究方向 > 学位 > 性别**。在本规则中：

- 教授群体（职称）在$S_i$得分中已整体偏高，7号和2号均为教授，自然获得了最高配额与最优选队位序——职称效应已通过$S_i$间接体现。
- 研究方向、学位、性别在问题2中发现的信息增量有限，不在规则中重复加权，避免了"同一个因素被重复利用"的逻辑问题。
- 这验证了"以$S_i$为单一排序变量是充分的"这一规则设计前提。

## 七、模型评价

### 7.1 优点

1. **确定性**：给定$S_i$值，规则输出唯一确定，无随机因素，可复现。
2. **硬约束保证**：通过配额修正算法保证$3 \le q_i \le 10$且$\sum q_i = 175$恒成立。
3. **分配公平性**：多轮次轮转分配避免了头部教师垄断优质队伍，尾部教师在早期轮次仍有3次选队机会。
4. **可解释性**：三个模块的决策逻辑线性清晰，无需复杂的优化求解器即可运行。
5. **与Q1/Q2衔接紧密**：分配的唯一变量来自Q1的$S_i$，规则合理性由Q2的因素分析提供支撑。

### 7.2 不足与改进方向

1. **阈值主观性**：$\tau_1=70, \tau_2=40$及各组配额区间的设定虽然经过可行性验证，但具体数值的选择缺乏统一的优化准则，更多依赖经验判断。
2. **分配次序与队伍质量脱节**：Q3定义的轮转规则仅规定了"选队权"的先后顺序，没有考虑"队伍质量差异"对各教师最终分配结果的影响（留待Q4处理）。
3. **修正路径的不均匀性**：当前修正算法使得大部分B级教师被削至$q_{\min}$，B级内部不再存在配额差异，削弱了$S_i$连续值的区分能力。可考虑采用分数部分排序的修正策略以保留更多组内差异。

### 模块一：配额计算

```
1. 按 score 降序排列 → 计算 P[i] = (M-1-rank)/(M-1)*100
2. 分组: P[i]>=70→A, P[i]>=40→B, else→C
3. 连续配额:
   A: q0 = 7 + 3*(P-70)/30
   B: q0 = 5 + 2*(P-40)/30
   C: q0 = 3 + 1*P/40
4. q[i] = clamp(round(q0), q_min, q_max)
5. total = sum(q); delta = N - total
   delta>0: 按 score 降序加至 q_max
   delta<0: 按 score 升序减至 q_min
6. assert sum(q) == N
```

```
selection_order = sort by (-score, -guidance_years, teacher_id)
```

### 模块三：分配次序

```
pick_index = 1
第一轮: for round in 1..3:
           for idx in selection_order:

第二轮: remaining = [q[i]-3 for i in range(M)]
       while sum(remaining) > 0:
           for idx in selection_order:
               if remaining[idx] > 0:
                   pick_schedule[idx].append(pick_index++)
                   remaining[idx] -= 1
```
