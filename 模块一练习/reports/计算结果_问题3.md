- **第一轮**（pick_index 1\~105）：按选队次序循环 3 次，确保每人至少 3 队

## 五、验证结果

| 检验项 | 条件 | 结果 |
|:-----|:----|:----:|
| 总量约束 | $\sum q = 175$ | **通过**（175） |
| 个体约束 | $3 \leq q_i \leq 10,\ \forall i$ | **通过**（范围 3\~10） |
| 配额区间约束 | $q_i \in [q_{\min}^{(tier)}, q_{\max}^{(tier)}]$ | **通过** |
| 单调性 | $S_a \geq S_b \implies q_a \geq q_b$ | **通过** |
| 选队次序完整性 | $\text{selection_order} = \{1,\dots,35\}$ | **通过** |
| 分配位序总数 | $\sum |\text{pick_schedule}[i]| = 175$ | **通过** |
| 分配位序匹配 | $|\text{pick_schedule}[i]| = q_i,\ \forall i$ | **通过** |

因 A 级 $q_{\min}=7$，理论最小配额之和为 $77+50+42=169 \leq 175$，所有教师均在各自 $q_{\min}$ 约束内完成修正，无需突破下限。
