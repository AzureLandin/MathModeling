# 问题三最终交付说明

## 1. 最终采用方案

问题三正式提交方案采用 S2：

- F2 日内负载修正预测；
- Linear 光伏预测；
- 基于 F2 自身历史发布误差重建的 28 日窗口、q75 保护量；
- 仅在题目规定的 00:00、06:00、12:00、18:00 更新预测；
- 每次获得新预测后结合真实 SOC 重新优化剩余计划；
- 采用自由末态、公共 2025 年 1 月初始化和既有充放电反馈规则；
- 按实际交付时段电价结算普通购电、调整购电和应急购电费用。

不增加题目没有给出的 08:00 或 09:00 预报节点，也不继续引入 PCHIP、MPC、其他 q 水平或额外参数扫描。

## 2. 正式结果文件

正式结果文件为：

`附件/附件5/result3.xlsx`

工作簿包括：

1. 原始计划购电量：保存 00:00 版本的 `q0`；
2. 调整后购电量：保存滚动择优后实际采用的 `q_eff`；
3. 充放电量：按自然日和六个 4 小时区间汇总充电量、放电量及起止库存；
4. 紧急购电量：列出全部发生应急购电的时段和电量。

计划购电表按照模板的时间列写入：每个日期行对应当日 00:10 至次日 00:10 的144个时段；自然账本中的 00:00—00:10 段按照跨日模板规则放入上一日期行的末端。储能汇总按自然日的 00:00—24:00 区间统计。

## 5. 论文使用口径

论文中将 S2 表述为“在2025年评价期和当前固定参数配置下费用最低的最终候选方案”，不表述为跨年度全局最优。费用下降主要来自应急费用减少，但逐日和逐月收益方向并不完全一致，因此应同时报告费用分解、应急电量变化和末期库存变化。
