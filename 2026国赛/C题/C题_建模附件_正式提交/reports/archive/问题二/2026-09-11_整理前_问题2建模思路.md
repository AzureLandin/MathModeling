# 问题2建模思路

状态：本文件保留原设计及后续候选方向。2026-09-11已完成首轮Baseline、8组分位数改进及终端2×2对照，当前方法与结果见问题二建模报告.md、问题二_首轮改进实验结果报告.md、问题二_终端目标对照实验结果.md；第二问尚未锁定最终方案。第一问已阶段性收敛；本方案继承其物理参数和单位体系，不默认继承其每天首尾相等条件。

## 1. 问题分析

第二问的核心是：每天0:00在不知道当天真实负载和光伏的条件下订购全天电量，并承担预测错误带来的经济后果。计划多买而未用完也要付费；计划不足且储能不能补足时，以5倍电价紧急购电。

| 项目 | 定义 |
|---|---|
| 输入 | 附件1重复的每日价格曲线、附件2在决策时已到达的历史、当前储电量 |
| 输出期 | 2025-02-01至2025-12-31，334天 |
| 指定展示日 | 3月20日、6月21日、9月23日、12月21日 |
| 日前决策 | 每天0:00固定144段计划购电量；当天普通计划不再修改 |
| 实时决策 | 根据已观测的当期供需与储电状态执行充放电、必要时应急补足 |
| 主要评价 | 实际计划费+实际应急费；同时报告应急量、事件、月度稳定性和约束误差 |

计划不可日内修订，不等于电池控制必须对预测误差无反馈。本方案显式假设储能可在运行中根据当前状态调节；它不能借机按普通价格增加计划外购电，所有额外外网供电按5倍应急价计费。

不能将附件2当天实际曲线作为0:00已知输入；不能使用附件3预报，否则混入第三问信息条件。全年实际数据是回测环境，按时间逐步揭示。

## 2. 数据预处理

### 2.1 时间与单位

沿用每段1/6小时，功率kW转电量kWh。预处理已有标准表results/audit/actual_2025_normalized.csv，但问题2仅取负载与光伏字段；价格重复附件1每日曲线，不取该标准表中附件4的波动价。

数值无缺失，不做无依据插补或平滑。负载的星期结构须由历史学习，不直接将周六、周日设为同类。原始采样点代表前一时段的离散化假设继续明确。

### 2.2 预测Baseline与时间切分

第一组简单候选：

- 负载：上周同一时段值；近期相同星期的同一时段均值。
- 光伏：昨日同一时段值；最近若干已结束日期的同一时段均值。

用$d$表示日期，$t$表示日内时段，可写：

$$\widehat L_{d,t}=\frac{1}{|\mathcal H_d|}\sum_{j\in\mathcal H_d}L_{j,t},\qquad \mathcal H_d\subset\{j:j<d,\ \operatorname{weekday}(j)=\operatorname{weekday}(d)\},$$

$$\widehat V_{d,t}=\frac1{|\mathcal D_d|}\sum_{j\in\mathcal D_d}V_{j,t},\qquad\mathcal D_d\subset\{j:j<d\}.$$

集合大小及取近几天/几周是待验证参数；历史不足时逐级回退到已有同类日、已有日均值。没有全年数据调参后回填早期预测。MAE、RMSE用于诊断；光伏含大量零值，不用普通MAPE作为主要评价。

1月用于按时间冷启动、形成历史并运行电池；初态按题面为6000 kWh。完全无历史的首日可设普通购电计划为零、储能暂不参与，以当期光伏供负载并应急补缺，作为透明但保守的初始化规则。这只是候选启动约定，不是题面要求；需检查2月初状态对冷启动选择的敏感性。不能用1月31日训练的模型回填1月运行。

## 3. 模型建立

### 3.1 统一符号与实际费用

$\Delta t=1/6$小时，$M=5000\Delta t$ kWh。$L,V$为负载、光伏功率（kW）；$p$为元/kWh。$q,e,c,d,w$分别为计划购电、应急购电、母线侧充电、母线侧放电、未使用电量（kWh）；$E$为电池内部电量（kWh）。为避免放电变量$d_t$与日期混淆，下式在单日内省略日期下标。

实际一天费用为：

$$C=\sum_{t=0}^{143}p_tq_t+5\sum_{t=0}^{143}p_te_t.$$

未用完的$q_t$不退款。$w_t$可含未使用购电，不能一律称为弃光。

供需平衡和储能约束为：

$$q_t+V_t\Delta t+d_t+e_t=L_t\Delta t+c_t+w_t,$$
$$E_{t+1}=E_t+0.9c_t-d_t/0.9,$$
$$0\le c_t\le Mz_t,\quad0\le d_t\le M(1-z_t),\quad z_t\in\{0,1\},$$
$$q_t,e_t,w_t\ge0,\qquad1200\le E_t\le10800.$$

这些是实际执行约束，不能把未来真实$L_t,V_t$提前放入日前模型求$q_t$。

### 3.2 第一版：点预测+日前MILP

每天0:00用$\widehat L_t,\widehat V_t$替代日前模型中的未知负载与光伏，建立第一问同类的MILP，预测场景中暂不设应急需求，最小化$\sum p_tq_t$。得到全天计划$q_t$及参考储电轨迹。

该第一版忽略预测误差分布，**不等同于期望总费用的全局最优策略**；它的用途是跑通闭环并形成应急费用对照。后续改进必须在相同执行规则和边界条件下比较实际费用。

终端处理需单独声明。候选最简设置为预测末态等于当日实际初态，用来抑制规划末端放空；这属于人为基线控制约定，不是第二问题面约束。实际日末不强制回到该目标，次日直接继承实测末态：

$$E_{d+1,0}=E_{d,144}.$$

后续将该约定与更长预测窗口或终端价值比较；不能因为第一问日循环就认定第二问实际状态每天首尾必然相等。延长规划窗口时，次日购电只为规划参考，须到次日0:00才正式确定。

### 3.3 实际执行：最简因果反馈规则

在时段运行中测得当期供需，令固定计划和光伏供电扣除负载后的剩余电量为：

$$r_t=q_t+(V_t-L_t)\Delta t.$$

当$r_t\ge0$时，先用富余充电：

$$c_t=\min\{r_t,M,(10800-E_t)/0.9\},\quad d_t=e_t=0,\quad w_t=r_t-c_t.$$

当$r_t<0$时，用电池补缺，仍不足则应急：

$$d_t=\min\{-r_t,M,0.9(E_t-1200)\},\quad e_t=-r_t-d_t,\quad c_t=w_t=0.$$

再按状态方程更新$E_{t+1}$。此规则自动保持非负、功率和容量限制并避免同时充放电，运算量每段为常数。它不考虑保留电量应对稍后更贵的应急需求，因此只是透明的执行Baseline，不能声称“先放电再应急”在所有情景下全局最优。

当期供需用于上述平衡，采用“运行中快速测量和反馈，10分钟代表功率近似区间运行”的理想化。它不表示日前已知当期未来数据，更不能将原始右端点样本说成区间起点已经观测；若研究控制延迟，需改用滞后测量和更细时间仿真。

### 3.4 根据Baseline证据再升级

若发现应急费较高，先考虑历史净负荷误差的偏差修正或按过去残差分位数设置安全余量。保护程度依据历史回测总费用选择，不把“固定多买10%”作为无来源结论。电池备用需同时考虑容量、功率及连续误差路径；只看单段RMSE不足以判断电池是否能补缺。

若误差呈连续成段、不同季节结构明显，可构造保留负载—光伏相关性和时间相关性的历史残差场景，进一步近似最小化：

$$\min_{q,\pi}\left[\sum_t p_tq_t+\mathbb E\!\left(5\sum_t p_te_t^{\pi}\mid\mathcal I_{d,0}\right)\right],$$

其中$\mathcal I_{d,0}$为当日0:00信息，$\pi$为只依赖已观测历史与当前状态的储能控制策略。期望由当时已有历史生成的场景近似。不能允许每个场景内的电池控制提前知道整天误差路径；否则是乐观的完美信息下界，不是可执行策略。可先固定因果控制器评估候选计划，或在多阶段场景树中施加非预知约束。

## 4. 模型求解与验证安排

实施顺序：

1. 加载当日0:00之前的数据及继承储电状态，形成144点预测。
2. 求解日前MILP，冻结当天$q_t$，保存预测、计划及发布时间。
3. 当天按144段揭示实际供需，执行反馈储能规则，应急补足并逐段记账。
4. 日末保存实际状态，进入下一日；2—12月输出，1月过程留作初始化证据。
5. 对第一版进行诊断，再逐项引入误差余量、备用控制或场景改进。

MILP采用第一问已有HiGHS内核，初态和终端条件需参数化，不能沿用脚本内硬编码6000作为所有日期初态。计算参数集中管理，固定随机种子（若生成场景），记录求解状态、gap和耗时。尚未确定的窗口、备用参数和停止条件在实现时说明，不预填所谓最优参数。

至少验证：

- 全部时段供需平衡、状态递推、功率/容量与互斥约束；普通购电计划日内冻结。
- 预测及参数的信息截止时点，禁止未来实际值泄漏；不使用附件3和附件4的信息。
- 日初继承前日实测末态，1月启动透明；不同方法使用匹配的初始、终端与结算条件。
- 计划費与应急费分开核算，未使用计划仍付款；紧急事件按连续区间合并，跨午夜按模板拆开。
- 2—12月实际总费用、逐月费用、应急量与事件，及4个指定日期的表1/表2/表3。
- 简单预测之间的时序回测；改进模型相对点预测Baseline的实际费用优势，而非仅比较预测RMSE。
- 检查长时间负误差、高净负荷、储能触边等场景；扰动和日期块Bootstrap在需要量化不确定性时再做。

由于应急购电被允许且本模型没有应急购电上限，补足后供电满足是模型机制保证，不能将“没有停电”当作独特模型优势。主要区分应急之前的缺额与为补足它实际支付的费用。
