当前候选是 **T_q80_6000**：先预测当天负载与光伏，再用历史误差修正需求，生成全天购电计划，最后用真实供需运行电池并核算费用。

| 环节 | 当前采用 |
|---|---|
| 预测 | 负载用 7 天前同段，光伏用昨日同段 |
| 风险修正 | 各时段最近 28 日残差的固定 q80 |
| 日前优化 | HiGHS 求解 MILP，名义日末目标 6000 kWh |
| 实际执行 | 富余充电、缺口放电、不足按 5 倍价应急 |
| 跨日 | 继承实际储电量，不每日重置为 6000 |
| 评价 | 2—12 月 334 天计划费加应急费 |
