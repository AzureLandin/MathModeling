# C题流程图绘制注意事项与示意结点

## 1. 文档定位

本文档用于指导绘制 C 题《微网与外部电网电力调控策略》的流程图和逻辑节点图。

本版采用以下原则：

- **每个阶段单独成图**，不再把所有内容堆进一张长图。
- **一个节点只表达一件事**，节点内不写成段说明。
- **主流程只保留关键动作**，公式、参数和结果数值放在图注或正文。
- **每张图控制在 5～8 个主节点**，最多不超过 10 个节点。
- **一条主线贯穿全图**，辅助信息用侧边注释，不与主流程争夺视觉中心。

当前研究状态必须准确表达：

- 问题1已经完成求解与验证，正式模型为确定性 MILP。
- 问题2处于建模设计阶段，尚未完成全年回测。
- 问题3、问题4尚未实现，目前只有推荐路线。
- 问题2至4使用虚线边框或“待验证”角标，不能画成已获得最终结果。

---

## 2. 简洁绘图总则

### 2.1 一个框只放一个节点

正确示例：

```text
建立144个10分钟时段
```

```text
功率转换为电量
```

错误示例：

```text
建立144个10分钟时段，完成右端点映射，
再将功率乘1/6小时转换为电量并检查异常值
```

### 2.2 节点文字长度

- 推荐每个节点 4～10 个汉字。
- 最多使用两行。
- 每行不超过 10 个汉字。
- 节点用动宾结构，如“统一时间轴”“构建MILP”“核验约束”。
- 不在节点中写完整公式。
- 不在节点中罗列三个以上参数。

### 2.3 信息层级

每张图只保留三类信息：

1. 主流程节点。
2. 必要判断节点。
3. 一处简短侧注或图注。

公式、模型规模、求解器参数、全部结果值和敏感性数据应放在正文或表格中，不进入流程框。

### 2.4 形状规范

| 形状 | 用途 |
|---|---|
| 平行四边形 | 数据输入、结果输出 |
| 圆角矩形 | 数据处理、状态更新、普通步骤 |
| 直角矩形 | 数学模型或求解器 |
| 菱形 | 是否通过、是否缺电等判断 |
| 圆柱体 | 历史数据、储能状态、费用账本 |
| 虚线框 | 待实施模块、可选增强模块 |

### 2.5 颜色规范

全篇固定以下颜色语义：

| 颜色 | 含义 |
|---|---|
| 深蓝 | 输入数据、购电计划 |
| 橙色 | 光伏、电价、经济信号 |
| 绿色 | 储能、可行结果、通过验证 |
| 红色 | 应急购电、风险、未通过验证 |
| 紫色 | 预测、随机场景、MPC |
| 灰色 | 约束、检查、辅助说明 |

颜色只作为辅助编码。黑白打印时还应依靠形状、线型和文字辨识。

### 2.6 箭头规范

- 主流程使用实线单向箭头。
- 反馈修正使用细虚线回箭头。
- 可选增强模块使用虚线箭头。
- 不交叉连线；无法避免时改用分阶段图片。
- 每条箭头最多标注 2～4 个字，如“通过”“不通过”“富余”“缺额”。

### 2.7 版式规范

- 每张图采用横向或纵向单主线，不使用复杂网状结构。
- 图标题只说明阶段名称，不写研究结论。
- 图中留白面积建议不低于 30%。
- 统一节点宽度和间距。
- 同层节点对齐，避免大小不一的文本框。
- 论文插图优先使用白底，禁止发光、渐变、3D和复杂装饰图标。

## 6. 图3：问题一 MILP 模型结构图

### 6.1 图的任务

清楚表示目标函数、变量和约束之间的关系。该图不展示预处理过程和求解结果。

### 6.2 推荐布局

采用“中心模型 + 四周模块”的放射结构，中心只放一个节点。

```text
                   [目标函数]
                       ↓
[决策变量] → [确定性MILP] ← [状态变量]
                       ↑
                   [约束集合]
```

约束集合再展开为五个独立小节点：

```text
[供需平衡]
[状态递推]
[容量边界]
[功率限制]
[充放互斥]
```

日循环条件作为第六个约束节点：

```text
[初末状态相等]
```

### 6.3 主节点文字

1. `确定性MILP`
2. `最小化购电费`
3. `决策变量`
4. `储能状态`
5. `供需平衡`
6. `状态递推`
7. `容量边界`
8. `功率限制`
9. `充放互斥`
10. `初末状态相等`

### 6.4 变量侧注

决策变量节点下方只写：

```text
购电、充电、放电、未使用电量
```

储能状态节点下方只写：

```text
电池内部储电量
```

### 6.5 公式处理

主图不写完整公式。如果确需展示公式，建议在图下另设一个窄公式栏，只放三条：

```text
目标函数
母线供需平衡
储能状态递推
```

互斥、边界和初末状态公式放在正文，不进入主图。

### 6.6 图注建议

> MILP以全天购电费用最小为目标，通过二进制变量约束储能在任一时段不能同时充放电，并满足供需平衡、状态递推和日循环条件。

## 7. 图4：问题一优化求解流程图

### 7.1 图的任务

只展示模型如何交给求解器并获得候选最优解。

### 7.2 推荐布局

采用五节点纵向流程。

```text
[载入标准数据]
      ↓
[构建MILP矩阵]
      ↓
[设置变量边界]
      ↓
[调用HiGHS求解]
      ↓
[获得候选最优解]
```

### 7.3 节点文字

1. `载入标准数据`
2. `构建MILP矩阵`
3. `设置变量边界`
4. `指定整数变量`
5. `调用HiGHS求解`
6. `获得候选最优解`

“设置变量边界”和“指定整数变量”可以并列汇入求解器：

```text
[设置变量边界] ─┐
                 ├→ [调用HiGHS求解]
[指定整数变量] ─┘
```

### 7.4 侧注

只在求解器节点旁写：

```text
分支定界求解MILP
```

## 8. 图5：问题一结果验证流程图

### 8.1 图的任务

表现“求解器返回解”并不等于直接接受结果，必须经过约束和最优性核验。

### 8.2 推荐布局

采用“候选解 → 并列检查 → 判断 → 输出/返回”的结构。

```text
                     ┌→ [供需平衡]
                     ├→ [状态递推]
[候选最优解] → [结果核验] ├→ [容量功率]
                     ├→ [充放互斥]
                     └→ [初末状态]
                              ↓
                       <是否全部通过?>
                       ↙             ↘
                 [返回检查模型]     [确认有效解]
```

### 8.3 主节点文字

1. `候选最优解`
2. `供需平衡检查`
3. `状态递推检查`
4. `容量功率检查`
5. `充放互斥检查`
6. `初末状态检查`
7. `最优性差距检查`
8. `是否全部通过`
9. `返回检查模型`
10. `确认有效解`

### 8.4 判断分支

```text
否 → 检查时间、单位、参数和约束 → 返回MILP模型
是 → 确认调度结果有效
```

“检查时间、单位、参数和约束”应拆成一个回退节点，不要在菱形中写长句。

### 8.5 数值展示原则

图中只突出以下两项：

```text
最大约束残差 < 10⁻¹² kWh
MIP gap = 0
```

其余详细残差放入正文表格。
