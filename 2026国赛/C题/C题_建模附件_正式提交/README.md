# C题建模附件正式提交包

本目录按比赛附件用途整理，未包含历史实验、审计草稿、缓存文件和重复格式图片。

| 目录 | 内容 |
|---|---|
| `附件/` | 附件1至附件4原始输入数据 |
| `code/` | 四问模型总入口和统一 CSV 数据处理代码 |
| `result/` | 五份正式结果 Excel、六份调度明细 CSV、汇总 CSV 与导出清单 |
| `figure/` | 按 q1 至 q4 分类的论文主图和求解流程图，统一保留 PNG |

问题四的 `result4-2.xlsx`、`result4-3.xlsx` 来自已通过回读核查的正式填报副本，分别对应 Q42 和 Q43_S2，不是空白模板。

正式 CSV 的评价区间为 2025-02-01 至 2025-12-31；问题一为附件1确定性单日。完整字段、行数、来源哈希和导出哈希见 `result/四问_正式结果导出清单.json`。

本包可独立查看附件、结果和图片，也可核验已有 CSV。完整模型重新训练或求解仍依赖原项目中的计算内核和冻结账本。
