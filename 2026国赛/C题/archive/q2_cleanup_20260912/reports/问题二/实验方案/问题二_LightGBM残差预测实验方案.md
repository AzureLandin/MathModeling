## 1. 问题分析

### 1.1 目标与模型分工

检验：同样的历史特征下，浅层梯度提升树能否利用非线性及特征交互，改善岭回归的残差预测，并降低既定调度系统的实际现金费用。

每日0:00预测当天144段负载功率和144段光伏功率，单位kW。购电量仍由MILP决定。树模型的历史信息通过滞后特征输入，模型不会自动知道日期先后；每个目标跨所有时段共享一个模型，不为144段分别拟合。

$$
\text{季节性朴素预测}+\text{LightGBM功率残差修正}
\longrightarrow\text{非负处理及光伏门控}
\longrightarrow\text{本组W28/q80}
\longrightarrow\text{日前MILP与实际反馈}.
$$

### 1.3 待验证机制与风险

树可能表达“近期变化对不同发电水平或时段的作用不同”等条件关系，但不能据此提前宣称本数据确有可利用的非线性。56日乘144段最多8064行，行之间相关，不等于8064个独立样本；限制树规模以控制过拟合。缺少天气预报时，历史特征无法保证预测突发天气变化。树的范围外外推能力有限，保留朴素水平参照也不能完全解决此问题。

预测精度、q80覆盖率和实际费用分别评价。与岭回归的比较是完整预测算法的对照，不能将所有差异都归因于非线性：岭回归保留已有前向选lambda，LightGBM使用固定参数。

## 2. 数据预处理

### 2.1 来源和标签

使用冻结读取器检查附件1/2哈希、日期、365乘144规模、有限值、非负性及单位。保留微小光伏值，不平滑、删异常日、随机打散或使用全年最大值截顶。原本不存在的缺失/非有限值须定位，不能静默插补。

令 $k=0$ 为1月1日，$t=0,\ldots,143$。朴素预测为

$$
b^L_{k,t}=\begin{cases}L_{k-7,t},&k\ge7,\\L_{k-1,t},&1\le k<7,\end{cases}
\qquad b^V_{k,t}=V_{k-1,t}\quad(k\ge1).
$$

训练目标 $u^Y_{j,t}=Y_{j,t}-b^Y_{j,t}$，$Y\in\{L,V\}$，为有符号功率残差，kW；不取绝对值，不使用岭回归误差作标签。1月1日没有有效预测或预测残差。特征有效日之前回退朴素，其真实发布误差可用于后续q80，但不制造训练行。

### 2.2 固定特征字典

沿用岭回归已有15/8个原始特征及顺序。定义 $a^Y_j=144^{-1}\sum_{s=0}^{143}Y_{j,s}$，日内周期四列为

$$
H_t=\left(\sin\frac{2\pi t}{144},\cos\frac{2\pi t}{144},
\sin\frac{4\pi t}{144},\cos\frac{4\pi t}{144}\right).
$$

| 负载列 | 定义 | 原始单位 |
|---|---|---|
| `l_base` | $b^L_{k,t}$ | kW |
| `l_yesterday_minus_base` | $L_{k-1,t}-b^L_{k,t}$ | kW |
| `l_known_week_change` | $L_{k-1,t}-L_{k-8,t}$ | kW |
| `l_sameweekday_mean_minus_base` | $|A_k|^{-1}\sum_{r\in A_k}L_{k-7r,t}-b^L_{k,t}$；$A_k=\{r\in\{1,2,3,4\}:k-7r\ge0\}$ | kW |
| `l_daily_week_change` | $a^L_{k-1}-a^L_{k-8}$ | kW |
| `weekday_tue`至`weekday_sun` | 当日星期的6个0/1列，周一为参照 | 无量纲 |
| `sin1,cos1,sin2,cos2` | $H_t$ | 无量纲 |

| 光伏列 | 定义 | 原始单位 |
|---|---|---|
| `v_base` | $V_{k-1,t}$ | kW |
| `v_recent_change` | $V_{k-1,t}-V_{k-2,t}$ | kW |
| `v_week_mean_minus_base` | $7^{-1}\sum_{r=1}^{7}V_{k-r,t}-V_{k-1,t}$ | kW |
| `v_daily_change` | $a^V_{k-1}-a^V_{k-2}$ | kW |
| `sin1,cos1,sin2,cos2` | $H_t$ | 无量纲 |

负载特征首次有效 $k=8$（1月9日），光伏 $k=7$（1月8日）。同星期均值仅用已有周；不能硬编码常规周末低负载。星期按运行日期定义，不按最后一个次日00:00样本改日。

每条历史训练行 $(j,t)$ 的特征必须以第 $j$ 日0:00以前的信息构造，后来可添加其真实标签，但不能用第 $k$ 日均值重写历史特征。无额外月份、年周期、天气、价格、SOC、交互列或滞后列。特征由树自动交互。

### 2.3 训练窗口和预处理规则

每天、每类目标取此前56个日历日 $[\max(0,k-56),k)$ 内特征有效的完整日，按日期、时段升序排列，每日144行、等权。至少14个有效日才训练，否则残差修正为0；负载首次可训练 $k=22$（1月23日），光伏 $k=21$（1月22日），实现须断言。最多8064行，早期最少2016行；行数不作为独立样本量。

树模型使用原始数值特征，不标准化、不缩放目标、不新增截距列。0/1星期列按普通数值输入，不额外声明类别；全部列为有限float64。每个训练日构建新的LightGBM Dataset/模型，直方图分箱仅取当时训练数据；不得使用全年构造的Dataset或未来验证集作reference。

光伏训练保留全部时段，不根据当天真值剔除夜间或小功率段。最终预测才应用第3.3节统一门控；岭回归内部继续保留原训练标准化流程，不为本实验重写旧模型。

## 3. 模型建立

### 3.1 残差梯度提升树

负载、光伏分别训练 $f^Y_k$。平方损失初始化为当窗标签均值 $f_0=\bar u$，依次拟合修正树并更新

$$
f_m(\boldsymbol x)=f_{m-1}(\boldsymbol x)+\gamma h_m(\boldsymbol x),
\qquad \gamma=0.05.
$$

每轮以平方损失的一阶/二阶信息选择分裂和正则化叶值；采用LightGBM的CPU直方图GBDT和受深度约束的叶子优先生长。固定最多100轮，叶子数最多7、深度最多3。每个目标跨时段共享全部树，输出

$$
\widehat Y^{\mathrm{raw}}_{k,t}=b^Y_{k,t}+f^Y_k(\boldsymbol x^Y_{k,t}),
\qquad \widehat Y^+_{k,t}=\max(0,\widehat Y^{\mathrm{raw}}_{k,t}).
$$

这是逐步贪心构树，不声称找到函数空间的全局最优。训练中间的梯度残差不等于下游q80使用的已发布预测误差。

### 3.2 唯一固定配置、初始化与停止

使用 `lightgbm.LGBMRegressor`，负载和光伏同一配置，每天从头训练，不warm start。以下值正式运行前登记，不搜索其他组合：

| 参数 | 值 |
|---|---|
| `boosting_type`, `objective` | `gbdt`, `regression`（平方误差） |
| `n_estimators`, `learning_rate` | 100，0.05 |
| `num_leaves`, `max_depth` | 7，3 |
| `min_child_samples`, `min_child_weight` | 144，0.001 |
| `reg_alpha`, `reg_lambda`, `min_split_gain` | 0，1.0，0 |
| `max_bin`, `min_data_in_bin`, `subsample_for_bin` | 63，3，200000 |
| `colsample_bytree`, `subsample`, `subsample_freq` | 1.0，1.0，0 |
| `boost_from_average`, `feature_pre_filter` | True，False |
| `device_type`, `n_jobs` | `cpu`，1 |
| `deterministic`, `force_col_wise` | True，True |
| `random_state`, `data_random_seed`, `feature_fraction_seed`, `bagging_seed` | 均为20250911 |
| `verbosity` | -1；异常与状态另外写日志 |

保存 `get_params()`、实际booster参数、LightGBM/NumPy/SciPy版本和模型文件。未明确列出的参数记录实际版本默认值。若版本不支持所列参数，先记录依赖问题并修订登记，不能静默忽略。此配置的叶节点样本数约束不能保证跨日独立性；L2值也不与岭回归lambda直接等价。

不传未来 `eval_set`，不作early stopping、随机交叉验证或按全年费用选轮数。达到100轮停止；库因没有有效分裂而提前停止是正常分支，保存实际树数和原因，不补随机树。若所有训练标签的极差至多1e-8 kW，直接预测当窗标签均值，标记 `constant_target`，避免无意义训练。

历史不足是正常朴素回退；拟合异常、特征/输出非有限属于正式运行故障，应记录并停止对应运行，不能静默回退后宣称模型通过。保存有限但极端的预测及非负截断率，不用全年真值截顶。本轮取消前向超参数选择层：历史信息仅用于每日训练，效果通过真正的逐日前向发布回测评价。

### 3.3 统一光伏门控

三组均按16号规则后处理光伏：第 $k$ 日使用此前7日同段光伏最大值，找出大于1 kW的时段，取最早至最晚索引，两端各扩3段（30分钟）并限制在0至143；区间外置0，区间内保留非负预测。历史不足7日或全无有效发电时，保留非负预测。

该规则仅为历史支持区间代理，不能称为准确天文日落，也不能保证所有真实零光伏段预测都为零。所有组统一使用，门控后从各自真实发布档案重建q80。已有岭回归仍按14号流程选lambda，最后按16号门控，不重新用门控后误差选lambda。

### 3.5 本组q80、冻结优化与跨日状态

对每组 $s$，发布功率经后处理后定义

$$
\widehat n^s_{k,t}=(\widehat L^s_{k,t}-\widehat V^s_{k,t})/6,
\qquad \varepsilon^s_{k,t}=(L_{k,t}-V_{k,t})/6-\widehat n^s_{k,t}.
$$

训练标签 $u$ 是朴素功率残差（kW）；q80使用 $\varepsilon$，是本组当时实际发布净需求误差（kWh）。不得混用、重用旧岭回归q80，或用新模型回代历史重写旧档案。

第 $k$ 日逐段仅取 $j\in[\max(1,k-28),k)$ 的有效发布误差。样本 $m\ge7$ 时排序取第 $\lceil0.8m\rceil$ 个，否则取0；28日为第23个，不插值。保留负修正和负净需求，以 $\widetilde n=\widehat n+r$ 送入冻结MILP。三组同一规则不等于三组修正电量相同。

**训练与边界。** 核对负载/光伏首训1月23/22日、13/14日训练边界、无未来训练行、全零/常数标签、常数特征、无可用分裂、预测负值、门控历史不足/无有效发电/首末边界，以及q80少于7日、负修正与第23个顺序统计量。样例标注合成，不冒充附件结果。模型保存重载与直接预测一致；固定日期重复训练结果一致。

**数值与物理。** 全期从逐段账本独立核验

$$
q+e+d=n+c+w,\quad E_{t+1}-E_t=0.9c-d/0.9,
\quad \ell=0.1c+(1/0.9-1)d,
$$

$$
\sum(q+e-n-w-\ell)=E_{\mathrm{end}}-E_{\mathrm{start}}.
$$
