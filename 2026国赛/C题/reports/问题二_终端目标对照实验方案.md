# 问题二：终端目标匹配对照实验方案

登记日期：2026-09-11。原方案已在新策略运行前保存，本次接续期间补全符号、评价公式与交付要求，不改变已登记的候选、参数或主比较。原文归档在results/q2_revision_audit_20260911/terminal_plan_original.md。设计依据来自已用于诊断的2025年数据，不是独立盲测。新实验只改变名义日末目标，不改实际日初状态，不强行重置实际电池。

## 1. 问题分析

首轮B_adaptive未使用电量302.86万kWh，其中267.62万kWh出现在电池达到上限的时段；应急费85.17万元，其中80.35万元出现在电池耗至下限的时段。这说明满电弃余与缺电应急可在不同时段同时存在，不能凭“242天日末满电”推断全天储能失效。

原名义终端目标等于当天实际初态。如果保护需求使实际日末不断升高，次日规划也会要求较高的末态，可能维持较高库存并增加弃余。该机制是假说，需通过匹配对照检验；减少末态目标也可能削弱次晨缓冲、增加应急，不能预设必然省钱。

目标是辨识固定求解流程中名义终端规则对实际现金费用的影响。输入为日前可得的历史负载、光伏、固定电价和已执行实际初态；输出为每天144段普通购电计划、实际储能/应急轨迹及334天费用。保护水平与终端目标是两个实验因素；日初实际状态是内生状态，不是每天人为配平的实验参数。

## 2. 数据预处理

- 仅使用附件1的144点日内电价与附件2的365×144负载、光伏功率。冻结输入并核对SHA256、字段形状、日期与原值；不用附件3、4。
- 每段时长$\Delta t=1/6$小时，功率单位kW，全部流量及电池内部状态单位kWh，电价单位元/kWh。样本继续解释为前10分钟代表功率，不能称已知段初真值。
- 不对源数据平滑、删点或归一化。净需求$n_{k,t}=(L_{k,t}-V_{k,t})\Delta t$允许负值，保留光伏富余及充电机会。
- 预测器固定为$\widehat L_{k,t}=L_{k-7,t}$、$\widehat V_{k,t}=V_{k-1,t}$，负载不足7天回退昨日；首日采用原公共冷启动。
- 残差$\varepsilon_{j,t}=n_{j,t}-\widehat n_{j,t}$来自当时发出的预测。每天0:00只取$j<k$的有效日期，默认前日24:00数据即时到达；不得用今天实际量或后训练的拟合残差补历史。
- q80组逐时段取最近至多28个有效日期的经验分位数，排序后取第$\lceil0.8m\rceil$个值；不足7个有效日期则零修正并记录。保护需求为$\widetilde n=\widehat n+r$，$r$和$\widetilde n$均不截零；无修正组$r=0$。

这些处理只定义实验输入及信息边界，不构成“预测足够准确”或“q80最优”的结论。

## 3. 模型建立

### 3.1 固定矩阵

| 组 | 历史残差保护 | 名义日末目标 | 作用 |
|---|---|---|---|
| A_base | 无 | 当天实际日初电量 | 原基准复现 |
| B_fixed_q80 | 每段历史28天残差q80 | 当天实际日初电量 | 主对照复现 |
| T_base_6000 | 无 | 固定6000 kWh | 终端效应对照 |
| T_q80_6000 | 每段历史28天残差q80 | 固定6000 kWh | 主实验 |
| B_adaptive | W28、J14、原五候选 | 当天实际日初电量 | 仅用于当前代码版本完整复现 |

固定6000 kWh取既有初始电量与旧方案中的终端敏感性值，非全年搜索所得；不是题目强制要求。q80为首轮已设定候选，此次为隔离终端作用而固定，不据此宣称已找出最佳分位数。四个固定组构成2×2对照；不将B_adaptive与T_q80_6000的差额归因于单一终端因素。

### 3.2 物理模型与信息约束

单日省略日期下标，$q$为购电计划，$\bar c,\bar d,\bar w,\bar E$为名义充电、放电、未使用电量和内部储电，$\bar z$为二进制充电模式。名义模型为

$$\min\sum_{t=0}^{143}p_tq_t,$$
$$q_t+\bar d_t=\widetilde n_t+\bar c_t+\bar w_t,$$
$$\bar E_{t+1}=\bar E_t+0.9\bar c_t-\bar d_t/0.9,$$
$$0\le\bar c_t\le M\bar z_t,\quad0\le\bar d_t\le M(1-\bar z_t),\quad\bar z_t\in\{0,1\},\quad M=5000/6,$$
$$q_t,\bar w_t\ge0,\quad1200\le\bar E_t\le10800,\quad\bar E_0=E_{k,0},\quad\bar E_{144}=h_k.$$

原规则$h_k=E_{k,0}$，实验规则$h_k=6000$。每个固定组只改最后一个等式的右端项，其他约束和目标不变。6000是名义目标，不是对真实库存的强制重置。目标是否可由名义购电和充放电实现由求解器与约束核验确定，不在求解后强行裁剪真实状态。

实际控制继续按当前区间内代表功率快速反馈：富余充电，缺额放电，剩余缺口5倍价应急。购电计划在每日0:00冻结。预测为负载上周同段、光伏昨日同段；残差严格取已结束日期，负残差和负净需求保留。普通购电全部按计划付款；未使用电量不另加罚金，不提供售电收入。

共同1月预运行从6000开始，2月1日共同状态8801.462273333342；评价334天、48096段，各组独立连续继承实际状态。实际日末不强制等于6000或日初。

## 4. 模型求解与验证

### 4.1 算法与初始化

1. 复现公共1月，从题面6000 kWh开始连续执行；2月1日从同一8801.462273333342 kWh状态分叉。
2. 当日0:00计算历史点预测和保护需求，使用实际初态求解MILP并冻结$q$；各组求解器、矩阵变量顺序和配置相同。
3. 实际供需按时间揭示，以原贪心反馈得到$c,d,e,w$，支付$C_k=\sum p_tq_t+5\sum p_te_t$。内部状态递推后进入下一天；日末实际状态可以偏离名义目标。
4. 保存全过程，再由独立脚本对照原始附件重算费用、能量、日期和对照差额。算法与验证通过后才生成结果报告。

调用math_modeling环境下SciPy的scipy.optimize.milp/HiGHS，采用分支割框架，相对gap目标$10^{-9}$、每次时限120秒。每次有721个连续变量、144个二进制变量；固定组334次日前求解，控制每段常数复杂度。MILP最坏情况复杂度不作多项式保证；实际最优状态、gap和耗时逐日记录。B_adaptive的历史候选模拟增加求解次数，仅为复现服务，不用于此次终端参数搜索。

完成策略使用配置/源文件签名与输出哈希恢复；未完成策略重新运行，不从不完整CSV猜测内部状态。尚未实现单策略逐日恢复，必须如实记录这一限制。

### 4.2 事前评价与收敛规则

主比较为T_q80_6000减B_fixed_q80的实际总费用，负值表示终端改动更省钱。同步比较计划费、应急费、未使用电量、次晨0—10时应急费、日末满电天数、储能损耗和四个指定日期。辅助比较T_base_6000减A_base，并给出两者的差中差，描述保护与终端规则的交互；这是仿真对照，不宣称具有总体统计显著性。

记$C_{a,h}$为保护条件$a\in\{\mathrm{base},q80\}$和终端规则$h\in\{\mathrm{cycle},6000\}$下的334天费用。固定对比为

$$\Delta_{q80}=C_{q80,6000}-C_{q80,\mathrm{cycle}},\qquad\Delta_{base}=C_{base,6000}-C_{base,\mathrm{cycle}},$$
$$I=\Delta_{q80}-\Delta_{base}.$$

两组终端效应分别报告，不能把交互$I$当作某一组的节费额。状态轨迹差异是策略的累计后果，不能每天重新对齐初态后仍称连续运营对照。

次晨0—10时为slot 0—59；全评价期按334个清晨汇总，另外保存2月1日日末至12月31日清晨的333组连续衔接。12月31日以后的实际数据不存在，不模拟或虚构次晨结果。日末满电定义为$E_{k,144}\ge10800-10^{-6}$ kWh；它不等同全天满电。应急/弃余触边按仅状态限制、仅功率限制、同时限制、均未触及四类互斥汇总，分类只说明共现，不证明扩容收益。

现金费用是主指标；ν=median(p)/0.9的年末存量调整只作诊断。月度改善、最差日期及各限制类型必须完整报告。若新组更差，保留负面结论，不追加参数搜索到取得正收益为止。

通过标准：共同初态和日间连续；购电及充放电非负；功率、容量、互斥、平衡和递推误差不超过1e-6；累计费用与能量复核不超过1e-4；未出现求解回退；未来扰动不改变当日日前输出。保存实际最大误差及文件哈希。

补充核验：逐段对照原始负载、光伏和电价；检查五组点预测完全相同、两个匹配对照保护量相同、名义末态确实满足对应目标；逐日、逐月、事件和全期费用独立核算。能量恒等式为

$$\sum_t(q_t+e_t+V_t\Delta t-L_t\Delta t-w_t)=\sum_t[0.1c_t+(1/0.9-1)d_t]+E_T-E_0.$$

通过数值与因果检查只代表该实验有效。若全年费用降低但部分月份恶化，应报告季节差异；若终端方案更贵，则记录反例，不自动添加新目标值或将6000择优删除。若现金与存量调整结论冲突，则仍保留未收敛状态。固定目标优于原规则也不等于目标值全局最优，备用、MPC和柔性终端仍须另立对照。
