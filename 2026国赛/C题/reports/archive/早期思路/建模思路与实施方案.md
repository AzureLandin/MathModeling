# C题《微网与外部电网电力调控策略》建模思路与实施方案

依据本目录 Markdown 赛题、原始 PDF 及附件结构核验整理。本报告提出建模路线、关键公式和验证方案；尚未求解全年调度，也不将预期改进写成已经取得的结果。

## 1. 推荐主线与优先级

建议采用 **混合整数线性规划（MILP）作为物理调度内核，配合概率预测、因果实时储能控制和带调整费用的模型预测控制（MPC）**。四问共用一套储能约束、时间轴、费用账本和仿真器，逐问改变可用信息及交易权限。

| 问题 | 核心难点 | 推荐具体模型 | 必做对照 |
|---|---|---|---|
| 问题1 | 电池效率、功率和容量约束下的经济调度 | 确定性混合整数线性规划 MILP；经验证可用 LP 简化 | 无储能、简单峰谷充放电规则 |
| 问题2 | 0:00 决策时不知道当天真实负载与光伏，缺电价格为5倍 | 季节性朴素预测／LightGBM 分位数回归 + 场景随机日前规划 + 因果实时储能控制 | 点预测 + 确定性 MILP |
| 问题3 | 新预报有价值，但调增和调减都有结算影响 | 带分段线性调整费用的经济 MPC；有余力加入随机情景与 CVaR | 仅0:00预报、固定四次更新 |
| 问题4 | 电价与净负荷共同影响储能价值 | 电价与净负荷联合情景 + 风险约束随机 MPC | 已知未来电价的理想对照、预测电价的可执行策略 |

最低可交付版本为“预测 + MILP + 严格按时间运行的仿真”；竞争力主要来自正确的信息时点、费用口径、跨日控制和有效实验。CVaR、动态备用等增强模块应逐个验证后加入。题目未给出线路拓扑、节点电压、可调负载或储能扩容决策，不宜凭空构建潮流、需求响应或容量配置模型。

## 2. 已核实的题面与数据问题

### 2.1 Markdown 转换遗漏

原始 PDF 第2页明确：问题3调整购电量超过计划的部分，按交易时刻电价的 **1.5倍**计费；低于计划的部分，违约电价为 **50%**。Markdown 漏掉了1.5，同时将“问题2”的编号2漏掉。建模应以 PDF 为准。

### 2.2 时间轴存在实质性歧义

附件1的 `Sheet1!A2:A145` 从 `00:10` 到 `0:00+1`，共144个时点。附件2与附件4按同样方式排列；解析为连续时间后，覆盖2025-01-01 00:10至2026-01-01 00:00，共52,560个唯一时点，相邻10分钟。

但 `result1.xlsx` 的“计划购电量”表 `A2:A145` 从 `0:10-0:20` 到 `0:00+1-0:10+1`；全年模板的时段表头也从 `0:10-0:20` 开始，最后一栏为次日 `0:00-0:10+1`。这与题面要求的0:00—24:00日调度存在十分钟偏移。

建议先建立内部标准时段：`00:00–00:10, …, 23:50–24:00`。主分析可明确采用“样本时点为该时段右端点，功率作该时段代表值”的解释，用144个样本得到144个电量。它是一项离散化假设，不能说原数据已明确是区间平均功率。可用梯形积分作敏感性比较；所需0:00点只能来自前一天24:00、题1周期边界，或另行声明的初值规则。

输出前需要核对官方模板及可能的勘误，给出统一的时间映射。不能简单按行号把原始时点、内部时段和模板列配对，也不能默默把00:00–00:10的结果贴到00:10–00:20的标签下。跨日解析后不存在重复时间点，不应为了去重删掉每天的24:00。

### 2.3 光伏预报必须同时保留发布时间和预测目标时间

附件3的列为“预报1小时”到“预报24小时”，即发布后第1至第24小时，而非包含发布当时的24个小时。例如，1月1日18:00发布的第24小时预报指向1月2日18:00。

规范数据结构为：`发布时间 issue_time、目标时间 target_time、提前量 lead_time、预报功率`。日期合并单元格须先向下填充。任一决策只能使用发布时间不晚于当前时刻的预报。

整点到10分钟的主方案采用线性插值，并限制光伏预测非负。发布时点至第1小时的预测需要接上当前已观测值或此前已发布的预报，不能补入未来实际值。比较“整点复制六段”与线性插值的敏感性，不把插值当作新增预测信息。

### 2.4 初始状态与结果范围

附录规定2025-01-01 0:00储电量为6000 kWh；问题2—4输出2月1日至12月31日。可将1月用于初始化、逐步训练和储能预运行，但这是建模安排。

不能训练完1月后，再用该模型回填整个1月的在线运行历史。建议首日采用预先声明的冷启动规则，例如保持初始储电量、缺口应急补足；此后按已到达数据滚动训练和运行。2月1日初态来自1月31日的实际末态。

只有问题1明确要求每天首尾储电量相等。问题2—4应跨日连续运行，不能每天重置6000，也不能未经说明复制问题1的日循环约束。

### 2.5 结果模板语义

问题3“调整购电量”表只有每日一行、144个时段，没有6:00、12:00、18:00三个修订版本的维度。建议解释为每个时段最终生效的调整后绝对购电量；完整修订过程另存日志用于复核。没有调整的时段填原计划的有效量，不把增减量当作调整后绝对量。此解释应在论文中说明。

全年计划与调整表对应334天，即2月1日至12月31日。充放电及紧急购电模板中出现省略号，需要展开所需日期和事件，不能只填示例行。

严格匹配目标小时，并仅在实际光伏大于100 kW的样本上计算，1—6、7—12、13—18、19—24小时预测时距的全年WAPE依次为2.43%、6.26%、9.79%、13.82%。WAPE定义为绝对误差之和除以实际功率之和。该结果支持**按预报时距分层校准残差**，而非给全部时距添加同一误差分布。

对同一目标时刻比较更新，0:00与6:00预报的WAPE为7.87%与4.12%（4084对）；0:00与12:00为9.37%与1.71%（1946对）。两个比较采用各自重叠的白天目标集，不能把四个数当作同一批样本上的连续变化。这些全年误差只作描述与最终验证，不用于提前校准2月预测。

18:00发布的当日剩余6小时预报共2190个值，只有20个正值，最大8.7375 kW；对应整点实际光伏也没有超过100 kW。因此18:00更新对当日光伏的直接作用可能较小，需要重点考察其对次日预期、当晚储能及跨日状态的间接价值，而不能预设所有更新时间同样有效。

## 3. 四问共用的调度模型

### 3.1 变量与单位

每日144个时段，时长为 \(\Delta t=1/6\) 小时。使用母线侧电量建模：

| 符号 | 含义 | 单位 |
|---|---|---|
| \(\ell_t=L_t\Delta t\) | 时段负载电量 | kWh |
| \(v_t=P_t^{PV}\Delta t\) | 时段光伏发电量 | kWh |
| \(q_t^0\) | 0:00确定的计划购电量 | kWh |
| \(g_t\) | 该时段最终有效的常规购电量；问题1、2中等于原计划 | kWh |
| \(e_t\) | 紧急购电量 | kWh |
| \(c_t,d_t\) | 母线向储能充电量、储能向母线放电量 | kWh |
| \(E_t\) | 时段开始时电池内部储电量 | kWh |
| \(w_t\) | 无法消纳的剩余电量 | kWh |
| \(p_t\) | 电价 | 元/kWh |

题面未给出售电机制，主模型不设售电收入。允许供给大于负载，可用剩余电量变量使平衡写成等式：

\[
g_t+v_t+e_t+d_t=\ell_t+c_t+w_t,\qquad w_t\ge0.
\]

统一规定 \(q_t^0,g_t,e_t,c_t,d_t,w_t\ge0\)，防止实现时出现负购电、负应急电量或隐含售电。

\(w_t\) 可能包含未消纳的计划购电，不能直接全部称为“弃光”。如果报告光伏消纳率，需要进一步区分未消纳光伏与未使用购电，并明确电量来源分配规则。计划购电即使没有用完也须按所选结算规则计费。

### 3.2 储能约束

主模型解释“充放电效率90%”为充电和放电效率分别为0.9：

\[
E_{t+1}=E_t+0.9c_t-\frac{d_t}{0.9},
\qquad1200\le E_t\le10800.
\]

题面没有单独定义单向与往返效率，因此同时做“往返效率90%，两向各取 \(\sqrt{0.9}\)”的敏感性对照。采用主解释时，往返效率为81%；不能将充入1 kWh视为未来可放出0.9 kWh。

可用储能容量是9600 kWh，不能把标称12000 kWh全部用于调度。最大充放电功率5000 kW对应每10分钟母线侧电量上限 \(5000/6\approx833.333\) kWh。采用二进制变量 \(z_t\) 避免同时充放电：

\[
0\le c_t\le\frac{5000}{6}z_t,\qquad
0\le d_t\le\frac{5000}{6}(1-z_t),\qquad z_t\in\{0,1\}.
\]

上述功率上限按母线侧解释，与电量变量保持一致。若采用电池侧定义，功率和效率项必须一起转换。

MILP可直接表达这些约束。若尝试去掉二进制变量改用LP，需要检查所有时段是否同时充放电，并给出成立条件或与MILP结果对照。费用相同的多解可按“先最小费用，再最小充放电吞吐量”作二级择优，避免无意义循环；不凭空加入高额电池损耗费改变原题目标。

## 4. 问题1：确定性经济调度

推荐模型：**确定性MILP**。

\[
\min\sum_{t=0}^{143}p_tq_t^0,
\quad g_t=q_t^0,\quad e_t=0,\quad E_{144}=E_0.
\]

采用附录给定初态计算时，明确设 \(E_0=E_{144}=6000\)。若另外研究最优周期初态，可把它作为扩展实验，但不能一边声明初态6000，一边自由优化初态。

实施顺序：时间对齐与功率转电量；求解MILP；核验144段能量平衡、功率限制和端点约束；按题目表1汇总指定10分钟时段，按表2汇总六个4小时区间的充放电量。

解释结果时重点分析两件事：低价时购电储存以减少高价购电，以及给次日或午间的光伏保留储能空间。电池不应机械地在每个低谷充满。

忽略容量、光伏机会成本及其他约束时，谷价购电后高价使用的必要经济条件为

\[
p_{\rm high}>\frac{p_{\rm low}}{0.9\times0.9}.
\]

这可用于解释调度曲线，不能代替全时域优化。问题1宜提供一张上下对齐的日曲线图：负载与光伏、购电与充放电功率、储电量与电价。

## 5. 问题2：预测误差下的日前计划

### 5.1 先建立可复现的预测基线

日前决策只能利用当天0:00之前已经获得的数据。附件2当天实际负载和实际光伏是仿真环境，不能作为当天的已知预测输入。问题2不使用附件3的未来预报，以保持四问信息条件的区别。

建议预测模型依次比较：

1. **季节性朴素预测**：昨日同一时段、上周同一时段、最近若干相同星期类型的均值。它是必要的低成本基线。
2. **LightGBM回归与分位数回归**：特征包括时段、星期、年内日期编码、已观测的日/周滞后负载和光伏、历史滚动统计。所有滞后和滚动特征按发布时间构造；对于0:00之后的多个预测步，不能把当天已知于回测者但尚未发生的值当作滞后特征。
3. 分别预测负载和光伏，形成净负荷 \(N_t=L_t-P_t^{PV}\)；再与直接预测净负荷的方法比较。光伏夜间大量为零时，不宜用MAPE评估，使用MAE、RMSE、归一化MAE和分位数损失。

模型复杂度按滚动验证结果决定。虽然有52,560个10分钟样本，只有一年的季节覆盖，2月开始时更只有1个月历史；不优先采用大规模LSTM或Transformer。

### 5.2 让误差分布进入调度

推荐主模型为**场景随机日前规划 + 因果实时控制**。利用历史样本外预测残差构造净负荷情景：优先按完整日或连续时间块抽样，保留连续阴云、持续负荷高峰等误差的时间相关性。分别抽取负载和光伏误差时，还要保持两者相关关系。

从几十个场景起步，观察费用、应急电量与求解时间随场景数的变化；必要时用K-medoids保留代表轨迹并汇总被代表样本的概率权重。不能用“场景多”替代稳定性验证。残差必须来自过去按相同预测流程生成的样本外预测，不能用训练拟合残差冒充预测误差。问题3使用附件3时，进一步按提前小时数和发布时刻校准误差；长时距预报尚未实现的目标值不能用于当前残差更新。

记实时控制策略为 \(\pi\)，推荐目标为

\[
\min_{q^0,\pi}\ \sum_t p_tq_t^0
+\mathbb E\!\left[\sum_t5p_te_t^\pi\right]
+\lambda\operatorname{CVaR}_{\alpha}(C^\pi).
\]

这里 \(C^\pi\) 可定义为当天总费用，\(\lambda\ge0\) 控制风险偏好。先求 \(\lambda=0\) 的期望费用最小版本，再检验是否需要风险项。对场景费用 \(C_s\)、概率 \(\omega_s\)，CVaR可线性化为

\[
\operatorname{CVaR}_{\alpha}(C)
=\min_{\zeta,\xi}\left\{\zeta+\frac{1}{1-\alpha}\sum_s\omega_s\xi_s\right\},
\quad\xi_s\ge C_s-\zeta,\quad\xi_s\ge0.
\]

它度量最昂贵尾部情形的平均费用，参数需由过去验证期选择，正式结果仍按题目实际购电费用报告。CVaR建模依据见文末参考资料。

### 5.3 必须区分场景内优化与真实可执行策略

普通两阶段随机规划若允许每个场景独立决定全天储能轨迹，就隐含“实时控制提前知道全天场景”，会低估缺电费用。严谨做法是场景树加非预知约束：历史相同的节点采用相同决策。

竞赛中更易落地的路线是：日前场景模型选出固定 \(q^0\)，真实运行时每10分钟依据当前储电量、已获得的观测与过去数据更新储能动作；仅执行当前一步，随后用实际发生量更新状态。即使内部采用两阶段近似，也把场景追索费用和因果回测实际费用分开，不能称近似追索值就是全年实际费用。

尤其注意右端点采样的因果顺序：例如00:00决定00:00—00:10的电池动作时，不能读取00:10的实际样本。主仿真可采用“段初确定充放电，段末揭示本段实际供需，用应急电量和剩余电量被动补差，再更新状态”的顺序。这里应急补差是对区间内外网即时平衡的汇总近似。若希望电池也在区间内根据测量快速纠偏，需单独声明更细时间尺度的观测与控制假设，不把段末完整样本提前当作段初信息。

问题2允许实时纠偏的是储能及紧急补电；常规购电计划在0:00后锁定，不能借MPC偷偷改成实时正常电价购电。应急电量用于补实际缺口，不能把全年真实曲线交给储能控制器事后找最省钱的轨迹。

### 5.4 80%分位数的经济解释

在单时段、无储能、无剩余电价值、固定正电价的简化问题中，令随机净需求为 \(X\)，计划量为 \(q\)，则

\[
\min_{q\ge0}\ p q+5p\,\mathbb E[(X-q)^+].
\]

连续分布的内点最优满足 \(F_X(q)=0.8\)。这说明缺电昂贵时，只预测平均需求通常不够。该结论是依据本题费用结构的推导，**不是**所有时段都固定买80%分位数的依据；储能耦合、随机电价、调整权利都会改变最优量。

### 5.5 跨日末端价值

每天实际末态传给次日。为避免有限时域优化在末端把电池放空，可采用24—48小时滚动视域，或增加末端储能价值 \(-\widehat V(E_T)\)。价值函数仅由过去数据估计，未来超过已发布预报范围的部分使用自己的预测并标明来源。

末端价值是优化用的延续价值，不计入对外报告的实际购电费。比较不同策略时，还要统一评估期末储能处理，避免一方仅靠消耗更多期末存量表现为“更省钱”。

## 6. 问题3：有调整费用的滚动优化

### 6.1 控制流程

使用**经济模型预测控制（Economic MPC）**：

1. 0:00：读取当时发布的光伏预报，结合负载预测与真实初始储电量，确定当天原计划并保存。
2. 6:00、12:00、18:00：读取新预报和真实当前储电量，锁定过去已执行的时段，只优化未来尚可调整的购电量及储能动作。
3. 每10分钟：执行当前有效购电计划和因果储能控制，用真实供需完成平衡及应急补电，更新电池状态。
4. 日末：按每个时段最终实际发生的账目统一结算，生成日统计，传递储电量。

使用未来24小时预报可支持跨日规划，但次日尚未正式承诺的量只是内部计划，不能当作今天已经签订并结算的合同量。MPC在微网经济调度中的应用与“优化未来、仅执行当前一步”原理，见文末资料。

### 6.2 两种费用解释需要明确区分

设原计划为 \(q_t^0\)，最终有效常规购电为 \(g_t\)，定义

\[
a_t^+=(g_t-q_t^0)^+,\qquad a_t^-=(q_t^0-g_t)^+.
\]

实现分段费用时，使用 \(g_t-q_t^0=a_t^+-a_t^-\)、\(a_t^+,a_t^-\ge0\)。在下列两种正电价费用中，同时增大两个变量都会增加费用，因此优化会自动给出正负部分。尤其不能在B口径下仅写两个下界 \(a^+\ge g-q^0\)、\(a^-\ge q^0-g\)：由于减购项系数为负，缺少耦合等式会造成目标无界。

PDF明确了1.5倍和50%，但**没有明说取消部分是否退还原购电费**。建议在未获得进一步说明时，以保留原计划付款的字面口径作主计算，同时报告退款口径敏感性，避免把未写出的规则当作题面事实：

| 解释 | 单时段费用 | 经济含义 |
|---|---|---|
| A：原计划费用不退，下调另收违约费 | \(p_tq_t^0+1.5p_ta_t^++0.5p_ta_t^-+5p_te_t\) | 计划付款保留，下调增加费用 |
| B：取消部分退原价，再付50%违约费 | \(p_tq_t^0+1.5p_ta_t^+-0.5p_ta_t^-+5p_te_t\) | 下调每kWh净收回原价的50% |

一个很有用的一致性检查：在A口径、正电价、无成本弃余且无额外接入约束下，把有效购电量降到日前原计划以下，会比保持原计划更贵，因此“保持原计划并弃余”支配这种减购。最终购电量不低于日前原计划，不一定是求解器错误，而是费用规则的逻辑结果。若此前已上调，撤回部分上调仍可能节费；这与减至原计划以下是两回事。B口径使低于日前原计划的下调也具有直接节费动机。

论文不能略过这个差别，也不应将两种口径的费用优势混合比较。如果确定了官方解释，应统一所有模型与基线采用同一解释。

### 6.3 多次修订不能重复结算

还需声明相对原日前计划的最终偏差结算，还是每次相对上一版计划逐次成交。模板不提供合同规则，无法据此唯一判定。

实用主方案可声明：相对0:00原计划，按各交付时段最终有效偏差结算一次。在线计算时可用“新版本偏差费用减旧版本偏差费用”衡量调整增量；最终汇总原计划费用加最终偏差费用，不累加各轮针对同一原计划计算的全额费用。

如果采用逐次成交口径，则需逐笔保存基准量、增减量、交易价格和不可撤销费用，作为另一模型完整求解。不得一部分按最终净额，另一部分按每次增量混算。

### 6.4 如何回答是否需要其他时刻的预报

比较不更新、只使用部分更新时刻、使用全部0/6/12/18点预报的因果回测。将每个预报更新的价值定义为：在相同起始状态、结算规则及后续仿真条件下，使用更新前后的实际总费用差；同时统计应急电量和实际发生调整的时段数。

可以定义事件触发调整：仅当当前可得信息估计的“维持策略未来成本－调整后未来成本”超过阈值时执行修改。阈值在过去验证期选择，不能用当天真实未来费用事后决定是否调整。

附件3没有其他发布时间的真实预报，因此无法直接证实每小时新增预报的真实收益。可做明确标注的合成预报精度情景或完美信息上界分析，给出“在何种精度改进与费用条件下有价值”的结论。

题面未给出取得预报的成本，新增信息可以选择不用，理论最优值不会因此变差。需要区分“取得更多信息”与“每次取得信息都付费修改购电计划”；后者未必经济。

## 7. 问题4：波动电价下的联合风险调度

首先定义附件4电价的信息可得性及结算时点：

- 若假设0:00已经公布全天价格，可直接使用当天价格优化，但必须声明此前提。
- 若电价只能实时观察，则当天实际电价只能用于结算和回测，0:00规划必须使用价格预测。

针对“实时波动”的表述，建议主模型采用第二种解释，第一种作为已知未来电价的理想对照。在未说明“交易时刻”时，不要混用调整发布时价格和交付时段价格。一个可复现的主假设是：按电量交付时段价格结算，优化时预测该价格，实际发生后用真实值记账；如果是承诺时锁价，必须另建合同价格账本。

预测电价可先比较“昨日同一时段／最近同类日均值”、SARIMAX与LightGBM。SARIMAX中的外生变量必须在决策时可得，不能使用未来真实负荷作已知解释变量。

情景应联合抽取 \((L_t,P_t^{PV},p_t)\) 的预测残差，保留同一时刻的相关性及时间持续性。在随机电价下，紧急购电成本应计算 \(\mathbb E[5p_te_t]\)，不能替换成 \(5\mathbb E[p_t]\mathbb E[e_t]\)。成本最高的往往是缺额与高价同时发生的场景，而不是单独的最大误差。

附件4全为正价，价格情景可采用对数价格等正值建模方式。需检查直接叠加残差是否人为生成负电价；在本题未设并网购电上限且允许弃余的模型中，负价可能诱发无界购电，不能把情景生成错误误认为真实市场机会。

分别重算问题2和问题3，保持同一预测训练流程、初始条件、应急机制及费用解释。通过拆分实验区分收益来自电价预测、联合相关情景还是日内调整，不能仅将固定电价情形与波动电价情形的总费用直接相减并称为模型改进。

## 8. 优先考虑的创新点

这些是针对本题可检验的改进方向，不表示相关方法在学术上首次提出。优先完成前两项；每项都必须有消融对照。

| 优先级 | 创新方向 | 可实施方法 | 如何证明有用 |
|---|---|---|---|
| 高 | 面向购电损失的预测与风险选择 | 分位数预测或费用加权预测；按最终调度费选择参数，电价波动时使用联合场景 | 比较RMSE最优与费用最优模型的实际总费用、紧急购电和区间覆盖率 |
| 高 | 连续误差驱动的动态储能备用 | 用未来误差累计路径的分位数确定备用电量；同时预留吸收光伏盈余的空间 | 与固定备用量、无备用比较，在相近应急风险下比较费用 |
| 中高 | 预报更新的经济价值与事件触发调整 | 用当前信息估计更新收益，超过阈值才改变合同量 | 与每次固定更新、完全不更新比较费用及调整次数 |
| 中 | 储能跨日价值与可解释调度 | 延长规划窗口或估计末端价值；用LP松弛的对偶量解释边际价值 | 检查是否减少日末放空、次晨应急购电；比较不同终端设置 |

动态备用可用以下思路具体化。设未来一段时间的净需求预测误差电量为 \(\varepsilon_\tau\)，构造

\[
R_t=\frac{1}{\eta_d}Q_\beta\!\left(\max_{1\le k\le H}\left[\sum_{\tau=t}^{t+k-1}\varepsilon_\tau\right]^+\right).
\]

它关注误差的最大累计缺额，比只看单点误差标准差更贴近连续缺电风险。可以把 \(E_t\ge E_{\min}+R_t\) 作为软备用约束，并设置违反备用目标的代价；滚动求解时约束未来可决策的储能状态，而非只惩罚已经不可改变的当前实测状态。它是近似风险管理规则，并不自动保证供电可靠：仍须检查放电功率、名义储能轨迹、再充电机会和总体可行性。备用量过大会挤占光伏消纳空间，需通过回测权衡。

不宜直接将MILP的离散最优解称为具有普通LP对偶价格；对偶解释应明确来自LP松弛或固定整数状态后的连续问题。

## 9. 竞争力需要由实验支撑

### 9.1 验证设计

按时间滚动训练、调参与运行，不随机打乱全年数据。超参数、备用比例、风险权重、触发阈值只能用当时之前的数据选择。可以在1月末已有历史中做初始滚动验证，之后采用扩展窗口或固定长度历史窗口，窗口长度作为待验证选择。

不能全年数据调参后，再把2月以来的结果称为当时可执行的样本外收益。四个指定日期用于展示，全年2—12月用于评价；另外展示一个按预先规则选出的高应急费用日，帮助解释失效情形。

### 9.2 统一基线与指标

| 对照 | 用途 |
|---|---|
| 无储能 | 量化电池本身的价值；使用匹配的信息条件 |
| 简单峰谷规则 | 检验优化相对人工规则的增益 |
| 点预测 + MILP | 分离概率预测／风险管理的价值 |
| 概率模型，无日内常规购电调整 | 问题2与问题3的共同对照 |
| 固定四次更新与事件触发更新 | 检验是否存在不必要的修改 |
| 完美预知未来的离线模型 | 同一物理和结算条件下的费用下界；明确不可部署 |

至少报告：实际总费用、原计划费用、调整净费用、紧急购电费用及电量、紧急购电事件数、剩余电量、储能吞吐量、约束最大违反量、求解耗时及最优性差距。

紧急购电次数按连续时间段合并统计；日内10分钟片段与连续事件是两个不同指标。需要按模板逐日填写时，跨日事件在午夜拆分，并说明全年事件统计口径。

在优化模型允许应急电无限补足负载的设定下，最终供电满足率通常被约束保证，不能把“无停电”当作模型独有优点。区分“应急前供电缺额”与“应急后满足负载”。

### 9.3 必要检查与敏感性分析

1. 每个时段供需平衡；储能状态逐段守恒；充放电功率和容量界限无违规。
2. 所有计划、修订、预测模型与残差样本均有可追踪发布时间，无未来数据泄漏。
3. 计划电量、调整电量、应急电量分别记账；两种退款解释不能混用。
4. 日初日末状态跨日衔接；全部策略期末能量处理一致。
5. 10分钟电量汇总到4小时、全天、全年，数值相互一致；先保留精度再按模板显示。
6. 分别改变预测误差、场景数、CVaR权重、效率解释、末端价值及结算解释，说明结论是否稳定。

可按日或连续日期块重采样估计费用差的不确定性，保留时间相关性；不要把每个10分钟片段当成完全独立样本夸大统计显著性。

## 10. 推荐实施顺序与论文组织

1. 数据与口径：建立规范时间轴、预报版本表、真实数据表、费用函数和初态规则。
2. 先跑通问题1：求出满足所有约束的MILP解，完成表1、表2及曲线解释。
3. 建立统一的因果仿真器：按时间获取信息、执行决策、结算费用，防止后续模型使用未来数据。
4. 完成问题2的点预测基线，再加概率情景；有明确尾部风险时引入CVaR或动态备用。
5. 加入0/6/12/18点预报版本和调整账本，完成问题3及信息价值分析。
6. 明确电价可见性，加入价格预测与联合情景，完成问题4。
7. 统一跑全年对照、敏感性和消融，核验四个指定日期及五个结果模板。

求解器可采用HiGHS处理LP/MILP，或团队已有的商业MILP求解器；HiGHS的模型支持见官方资料。优先利用本题线性结构，不把遗传算法、粒子群算法或强化学习作为主求解工具。除非新增了有依据且确实不能线性化的结构，否则它们增加的调参成本和可行性验证负担较难转化成收益。

团队可分为数据预测、优化仿真、实验论文三个方向；共同维护变量单位、时间索引和结算口径。论文围绕“确定性调度—误差风险—预报更新价值—电价联合风险”展开，各问之间说明模型继承关系。

建议重点呈现四类图：典型日供需和储能运行图；全年或月度费用分解；费用与应急风险的权衡曲线；预报更新／创新模块消融图。费用、应急风险和储能行为之间的解释，比堆叠模型名称更能支持结论。
