## 4. 模型建立

净需求预测与残差（单位 kWh，不重复乘 Δt）：

```
n_hat[g][k,v,h] = (load_hat[g][k,v,h] - pv_linear[k,v,h]) * dt
n[k,h]          = (L[k,h] - V[k,h]) * dt
eps[g]          = n - n_hat[g]
rho[g][k,v,h]   = eps[g]_(ceil(0.75 m))     # m >= 7；否则 0；允许负保护
protected[g]    = n_hat[g] + rho[g]
```

历史资格：`max(0,k-28) <= d < k` 且 `144d + h + 1 <= 144k + 6·r_v`（该目标区间已结束）。**F2 的 14 日权重拟合与 q75 的 7 日保护历史是两套机制，不得混用**；F2 只用自身已保存的发布值形成历史误差，不用 F0/F1 误差替代、也不用当前参数回代旧日期。

调度内核不变：功率上限 5000 kW（每槽 5000/6 kWh）、内部库存 1200—10800 kWh、充放电效率各 0.9、自由末态、无售电与新增惩罚；0 点最小化 `Σ p q⁰`，日内最小化 `Σ [p q + 0.5 p |q − q⁰|]`；候选须比旧计划评分低超过 1e-4 元才被接受。结算 `C = Σ [p q_eff + 0.5 p |q_eff − q0| + 5 p e]`，多次覆盖不累计重复调整费。
本轮实际求解：S2 正式 1336 次 MILP ＋ 适配检查 2 次；S0 全年重跑 0 次。保护重建是两组纯数组运算，**如实登记为 2 组重建，不称 0 分位重建**。
