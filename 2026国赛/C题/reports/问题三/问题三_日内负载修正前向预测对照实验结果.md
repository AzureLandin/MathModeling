## 1. 结论

1. **本轮判定：F2 在本年度前向回测中同时优于 F0 与 F1（主指标 A 集 10 分钟 MAE）：可称当天偏差模型比这两个基准的主指标更好，但需再结合 RMSE、各节点、月份与极端日判断是否值得设计费用对照，不自动升级模型。** 主指标为 A 集（每次更新后到下一发布节点前的 6 小时，覆盖 06:00—24:00 的 36,072 个唯一 10 分钟目标）的逐段 MAE：F0 142.2568 kW、F1 141.7249 kW、F2 133.1149 kW。**F2 比 F0 低 9.1419 kW（-6.43%），比 F1 低 8.6100 kW（-6.08%），即当天近期偏差提供的增量信息在本年度前向回测中确实改善了点预测主指标。**
2. **仅历史偏差校正（F1）本身不是可靠改进**：F1 只比 F0 低 0.5318 kW（-0.37%），逐月 6/11 更准、5/11 更差，在 06:00 节点几乎为零（141.7249 对 142.2568 kW）。F2 在三个节点上都更低，且逐月 **11/11** 优于 F0、8/11 优于 F1。
3. **但改进是均值意义而非普遍成立**，必须并列披露：F2 只在 53.54% 的 A 集目标上绝对误差更小（逐日 188 天更准、146 天更差）；逐日 MAE 差的中位数只有 -1.3263 kW，远小于均值改善（-9.1419 kW），说明均值优势由少数大幅改善日拉动；最差三日为 2025-07-27:+54.743612、2025-08-04:+33.286768、2025-07-15:+30.145720（正值=更差），最好一日 2025-09-03:-264.886852；改善最集中的 5 天（2025-09-03、2025-09-02、2025-12-02、2025-07-01、2025-12-03）合计占全天级净改善的 **33.91%**，即 −9.14 kW 不能读成稳定的逐日收益。
4. **午夜尾槽与偏差项不进反退**：1,002 条尾槽记录对应 334 个不同实际午夜区间，其 MAE 为 F0 163.0414、F1 166.2380、F2 163.4793 kW——**F2 在尾槽上并不优于 F0**（RMSE 反而更好）；F1 的平均偏差最接近零（0.2100 kW），F2 略偏负（-0.7843 kW）。
5. **这不是节费、也不是模型采纳**：本轮没有调度、没有储能回放、没有 q75 重建，MAE 改善不能读成成本下降；正式期滚动拟合中仍有 20.30% 的 β 为负、修正量范围达 [-788.6, 678.0] kW，属于小样本滚动不稳定，若要进入费用实验必须另外重建本组 W28/q75 并从各自连续的真实 SOC 轨迹运行。

## 2. 问题分析

问题二的 15 特征 LightGBM 每天 0:00 发布一次负载预测，问题三 6:00/12:00/18:00 仍沿用同一预测。前轮诊断确认「发布前已观测的负载偏差」与「发布后各小时残差」总体正相关，但 35/39 个统计格至少一个月反号、且不随距离单调衰减。本轮把该线索做成三组可执行对照，在真实信息边界下检验它能否改善 10 分钟级点预测，并把「一般历史偏差校正」与「当天新增信息」的作用分开。

本轮没有购电决策变量或现金目标：回归系数只是预测参数，评价对象是负载误差（kW）。原预测 F0 是基准且完全不动；F1、F2 都是在同一原预测误差上加修正，因此三组可用同一批目标逐条配对比较。

## 4. 模型建立

三组固定、不搜索：

| 组 | 预测 | 含义 |
|---|---|---|
| F0_original | 原预测 | 复用 0:00 原预测，不施加任何修正（基准） |
| F1_hist_mean | 原预测 + ȳ | 仅历史偏差校正：加过去 28 日该组未来残差均值 |
| F2_intraday_linear | 原预测 + a + β·b | 再加当天发布前 1 小时偏差 b，参数 a、β 同样只用历史估计 |

对每个 (发布日 k, 发布节点 r, 未来小时或尾槽 c) 用同一历史集合做闭式一元最小二乘：

```
beta = sum_d (b_d - bbar)(y_d - ybar) / sum_d (b_d - bbar)^2
a    = ybar - beta*bbar
delta1 = ybar                      # F1
delta2 = a + beta * b[k,r]         # F2
Lhat_g[k,h] = max(0, Lhat0[k,h] + delta_g[c])   h >= s_r
```

回退与数值边界：m < 14 时 F1、F2 修正都为 0 并回退 F0；当前 b 无效时 F2 回退 F1；历史 b 方差 ≤ 1e-10 kW² 时令 β=0、a=ȳ（F2 等于 F1）。β 不限正负、不强制小于 1、不施加任何衰减；修正量统一作用于该小时六个 10 分钟槽；每个节点都相对原 0:00 预测修正，不在上一节点校正值上累加；0:00 版本保持原预测。

实际估计与回退（共 14,235 个参数组）：闭式估计 13,650 次、m<14 回退 585 次、方差退化 0 次、当天 b 无效 39 次。回退全部集中在 1 月上旬（历史不足 14 日）与第 0 日（原档案该日无有效预测）。**本轮不是“0 拟合”**：确实做了 13,650 次滚动一元参数估计，但 LightGBM 训练 0 次、调度求解 0 次、储能回放 0 次。

## 7. 边界与限制

- 点预测误差不是费用：本轮没有调度、没有储能回放、没有 q75 重建，MAE 改善不能读成节费，也不能自动升级为正式模型。
- 主指标是 A 集逐段 10 分钟 MAE，事前固定、不得事后更换；小时均值只能作补充，不能用它代替逐段 MAE。
- 回归以平方误差估计、评价以 MAE 为主，二者不同；结果不佳也不能临时改主指标掩盖。
- 28 天参数窗口、14 日下限、按发布小时与未来小时分组都是工程设定，未证最优；本轮不调窗口、不加岭回归、不加门控、不按表现挑节点。
- 2025 年此前已参与方法设计，本轮仍不是跨年盲测，也不是独立样本外验证。
- B 集 73,146 条记录含重叠目标，只作发布版本质量诊断，不能当独立区间或替代 A 集。
- 1,002 条午夜尾槽对应 334 个不同实际午夜区间、被三个版本各预测一次，不能当成三次实际发生。
- 每小时内统一平移可能造成小时边界跳变或局部恶化，本轮只记录不修正。
- 截断前修正量与截断后实际变化分开记录：截断命中时两者不等，不能混称一个修正量。
- 没有任何图件经过目视核查（本 Agent 无法查看图像），只做程序化完整性检查。

- 参数不稳定性的口径：正式期 β 为负占比 20.30%、β 范围 [-1.179065, 3.660811]；`parameter_summary.csv` 的 `all_groups` 行含 1 月预热，数字不同（19.37%、最大 4.005550），引用时不得混用。

**预登记判断规则（方案 §4.4）**：以 A 集逐段 MAE 为第一道门槛，差值绝对值 ≤ 1e-8 kW 视为数值持平。F2 同时低于 F0 与 F1，才可称“在本年度前向回测中，当天偏差模型比这两个基准的主指标更好”；再结合 RMSE、各节点、月份与极端日判断是否值得设计费用对照，**不自动升级模型**。本轮落在此分支，且 RMSE、三个节点均同向改善，但尾槽 MAE 与 F2 的负偏差是并列反例。
