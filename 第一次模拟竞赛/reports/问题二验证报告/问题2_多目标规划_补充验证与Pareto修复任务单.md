# 问题 2：新增快慢充桩多目标规划
## 补充验证与 Pareto 解修复任务单

> **触发原因**：初版 NSGA-II + 熵权-TOPSIS 结果中，发现部分所谓 Pareto 候选方案存在可行的局部严格支配替代方案。例如，M-A 最终方案的区域 3 配置 \((x_3,y_3)=(11,5)\) 被 \((10,6)\) 严格支配。因此，需要在不改变原始问题 2 建模主线的前提下，增加候选解结构修复、局部支配扫描、重筛选及 TOPSIS 稳健性复核。

---

## 1. 原模型保留内容

以下内容不变：

1. 2026 年规划需求采用问题 1 中新能源汽车保有量增长 \(15\%\) 的基准情景；
2. 决策变量为 10 个区域的新增快、慢充桩数量：

\[
x_i,y_i\in\mathbb Z_{\ge0},\qquad i=1,\ldots,10;
\]

3. 目标 1 为总建设成本最小：

\[
f_1=\sum_{i=1}^{10}(6x_i+0.8y_i);
\]

4. 目标 2 为全市面积加权覆盖率最大：

\[
C_{\mathrm{city}}=
\frac{\sum_i A_iC_i}{\sum_i A_i};
\]

5. 每个区域均需满足覆盖率、服务能力、快慢充结构、整数与编码上界约束；
6. 目标 3 继续分别比较：

\[
\text{M-A: }f_3^{(A)}=\sum_{i=1}^{10}\nu_i^2,
\]

\[
\text{M-B: }f_3^{(B)}=\operatorname{Var}(\nu_i),
\]

其中新增接入容量压力率为：

\[
\nu_i=\frac{120x_i+7y_i}{G_i}.
\]

> \(\nu_i\) 表示“区域新增充电设施额定接入容量压力率”，不等同于问题 3 中的实际分时运行负荷率或峰谷差。

## 2. 发现的局部支配问题

初版 M-A 最终方案中，区域 3 为：

\[
(x_3,y_3)=(11,5).
\]

区域 3 的新增总桩数为：

\[
n_3=11+5=16.
\]

可行替代方案为：

\[
\boxed{(x_3',y_3')=(10,6).}
\]

二者满足相同新增总数：

\[
10+6=11+5=16,
\]

因此覆盖率相同。并且区域 3 的既有快慢充数量为：

\[
F_3^{(0)}=99,
\qquad S_3^{(0)}=66.
\]

替代方案满足快充结构约束：

\[
66\times10=660>99\times6=594.
\]

替代方案的服务能力为：

\[
80(99+10)+20(66+6)=10160\ \text{车次/日},
\]

明显高于规划需求：

\[
Q_3^{\mathrm{plan}}=991.96\ \text{车次/日}.
\]

而其新增成本和额定接入功率分别为：

\[
6\times10+0.8\times6=64.8\ \text{万元},
\]

\[
120\times10+7\times6=1242\ \mathrm{kW}.
\]

初版方案对应为：

\[
6\times11+0.8\times5=70.0\ \text{万元},
\]

\[
120\times11+7\times5=1355\ \mathrm{kW}.
\]

故 \((10,6)\) 同时降低成本与接入压力、保持覆盖率不变，严格支配 \((11,5)\)。

## 3. 结构化最小快充修复

### 3.1 修复原理

对给定区域 \(i\) 的新增总桩数：

\[
n_i=x_i+y_i,
\]

覆盖率仅由 \(n_i\) 决定。快充结构约束为：

\[
S_i^{(0)}x_i\ge F_i^{(0)}y_i.
\]

代入 \(y_i=n_i-x_i\)，得：

\[
(S_i^{(0)}+F_i^{(0)})x_i\ge F_i^{(0)}n_i.
\]

因此，满足既有快充比例不退化的最小快充数量为：

\[
\boxed{
x_i^{\min}(n_i)=
\left\lceil
\frac{F_i^{(0)}}{F_i^{(0)}+S_i^{(0)}}n_i
\right\rceil
=\lceil\theta_i n_i\rceil.
}
\]

对应慢充数量为：

\[
\boxed{y_i^{\min}(n_i)=n_i-x_i^{\min}(n_i).}
\]

在服务能力约束未被触发时，快充单位成本和单位额定接入功率均高于慢充：

\[
6>0.8,
\qquad120>7.
\]

故对于固定 \(n_i\)，采用最小可行快充数量会同时降低：

\[
\text{建设成本},
\qquad
\text{新增接入压力}.
\]

### 3.2 服务能力修正

每个候选方案先按上式得到 \((x_i^{\min},y_i^{\min})\)，再检查：

\[
80(F_i^{(0)}+x_i^{\min})+20(S_i^{(0)}+y_i^{\min})
\ge Q_i^{\mathrm{plan}}.
\]

若满足，直接采用该修复结果。

若不满足，则在新增总数 \(n_i\) 不变的前提下，逐步执行：

\[
x_i\leftarrow x_i+1,
\qquad
y_i\leftarrow y_i-1,
\]

直至服务能力满足或 \(y_i=0\)。

若 \(y_i=0\) 后仍不满足，则增加新增总桩数并重新执行最小快充结构修复，直至覆盖率、服务能力、结构与上界全部满足。

### 3.3 修复伪代码

```text
for each candidate solution z:
    for each region i:
        n_i = x_i + y_i

        # 保持总数不变，取满足服务结构的最小快充数
        x_i = ceil(theta_i * n_i)
        y_i = n_i - x_i

        # 若服务能力不足，则用慢充替换为快充
        while service_capacity(i) < Q_plan[i] and y_i > 0:
            x_i += 1
            y_i -= 1

        # 若总数固定时全快充仍不足，增加总数并循环修复
        while service_capacity(i) < Q_plan[i]:
            n_i += 1
            x_i = ceil(theta_i * n_i)
            y_i = n_i - x_i
            repeat fast/slow replacement if needed

        assert coverage constraint, service constraint,
               fast-share constraint, and n_i <= n100_i

    recompute f1, C_city, f3, nubar, nu_max, nu_std
```

## 4. 邻域支配扫描

结构修复后，仍应进行离散邻域检查，防止存在其他未被最小快充修复捕捉到的局部支配点。

对每个候选方案 \(\boldsymbol z\)，逐区域构造邻域：

\[
(x_i+\Delta x,y_i+\Delta y),
\qquad
\Delta x,\Delta y\in\{-1,0,1\}.
\]

要求替换后的变量满足：

\[
x_i+\Delta x\ge0,
\qquad y_i+\Delta y\ge0,
\]

以及全部区域约束。

对于每个可行邻域方案 \(\boldsymbol z'\)，检查同一模型下是否满足：

\[
f_1(\boldsymbol z')\le f_1(\boldsymbol z),
\]

\[
-C_{\mathrm{city}}(\boldsymbol z')\le-C_{\mathrm{city}}(\boldsymbol z),
\]

\[
f_3(\boldsymbol z')\le f_3(\boldsymbol z),
\]

且至少一个严格不等式成立。

若成立，则 \(\boldsymbol z\) 被邻域方案严格支配，必须从候选集中删除；若 \(\boldsymbol z'\) 为新方案，则可加入候选集。

建议迭代邻域扫描，直至候选集合不再变化或连续两轮无新增/删除方案。

## 5. 重建 Pareto 候选集

对 M-A、M-B 分别执行：

```text
1. 合并 5 个随机种子产生的末代可行非支配解；
2. 删除完全相同的 20 维整数配置；
3. 对每个候选方案执行“最小快充结构修复”；
4. 对修复后的方案再次去重；
5. 执行邻域支配扫描；
6. 在目标空间进行严格全局非支配筛选；
7. 输出修复前后：候选数、严格 Pareto 解数、被删除支配解数、修复方案数。
```

需要特别说明：NSGA-II 某一代的非支配排序仅针对算法当前种群或样本解集；补充步骤得到的才是“对已搜索候选集经局部修复后的严格非支配集”。不得把有限搜索结果表述为理论上完整的全局 Pareto 前沿。

## 6. TOPSIS 重算与权重敏感性验证

对修复后的 M-A、M-B Pareto 候选集，分别重算 TOPSIS。

### 6.1 指标矩阵

| 指标 | 记号 | 类型 |
|---|---|---|
| 总建设成本 | \(f_1\) | 成本型 |
| 全市面积加权覆盖率 | \(C_{\mathrm{city}}\) | 效益型 |
| 模型目标 3 | \(f_3^{(A)}\) 或 \(f_3^{(B)}\) | 成本型 |

### 6.2 三组权重

1. 熵权：

\[
\boldsymbol w^{\mathrm{entropy}}
\]

由修复后候选集的指标差异系数计算；

2. 等权：

\[
\boldsymbol w^{\mathrm{equal}}
=(1/3,1/3,1/3);
\]

3. 偏成本权重：

\[
\boldsymbol w^{\mathrm{cost}}
=(0.50,0.25,0.25).
\]

### 6.3 必须输出的原始指标对比

不能只输出“是否为同一解”。对每个模型、每种权重下推荐的方案，输出：

| 模型 | 权重方案 | 成本/万元 | 覆盖率 | \(\bar\nu\) | \(\nu_{\max}\) | \(\sigma_\nu\) | \(\sum_i\nu_i^2\) | \(\operatorname{Var}(\nu_i)\) | 新增快充 | 新增慢充 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|

### 6.4 稳健性判据

若三类权重选择的整数配置不同，但同时满足：

\[
\frac{|f_1^{(a)}-f_1^{(b)}|}{\max(f_1^{(a)},f_1^{(b)})}\le5\%,
\]

\[
|C_{\mathrm{city}}^{(a)}-C_{\mathrm{city}}^{(b)}|\le0.01,
\]

且 \(\nu_{\max}\)、\(\bar\nu\) 无明显恶化，则可称推荐结果对权重“指标意义上稳健”。

若差异超过该范围，则必须保留多个备选方案，不能仅将熵权-TOPSIS 第一名称作唯一最终最优方案。

## 7. M-A 与 M-B 的重新比较及选择规则

修复后仍不可直接比较两个模型各自的 TOPSIS 贴近度。应采用统一原始指标比较各自推荐方案：

| 指标 | 方向 |
|---|---|
| 总建设成本 \(f_1\) | 越小越好 |
| 全市覆盖率 \(C_{\mathrm{city}}\) | 越大越好 |
| 平均压力 \(\bar\nu\) | 越小越好 |
| 最大压力 \(\nu_{\max}\) | 越小越好 |
| 压力标准差 \(\sigma_\nu\) | 越小越好 |
| 压力平方和 | 越小越好 |
| 压力方差 | 越小越好 |

模型选择沿用原有规则：

1. 若 M-A 的成本和覆盖率不劣于 M-B，且 \(\bar\nu\)、\(\nu_{\max}\) 更低或相近，选 M-A；
2. 若 M-B 显著降低 \(\sigma_\nu\) 或 \(CV_\nu\)，同时成本、\(\bar\nu\)、\(\nu_{\max}\) 相比 M-A 的恶化均不超过 \(5\%\)，可选 M-B；
3. 若 M-B 仅降低方差，却明显提高 \(\bar\nu\) 或成本，则属于高压力伪均衡，拒绝 M-B；
4. 若两者差异较小，优先 M-A，因为：

\[
\sum_i\nu_i^2=10\operatorname{Var}(\nu_i)+10\bar\nu^2,
\]

压力平方和同时控制总体接入压力与区域集中风险。

## 8. 算法收敛与样本完整性诊断

初版每次运行的 Pareto 解数均为 240，恰好等于种群规模。该现象不一定是错误，但说明末代种群中大多数个体互不支配，Pareto 前沿可能较厚，TOPSIS 对候选集范围具有敏感性。

补充验证必须增加：

1. 每一代可行个体比例；
2. 每一代非支配个体数；
3. Hypervolume（若库支持）或目标空间归一化收敛指标；
4. 合并 5 个种子后去重数、修复数、邻域删除数、重筛选后的 Pareto 解数；
5. 修复前后最终推荐解的成本、覆盖率与压力指标对比。

若采用 Hypervolume，应在所有运行中固定同一个、明显劣于全部可行方案的参考点，不能为每个模型或每个种子单独改变参考点。

## 10. 补充验证通过标准

补充验证完成后，只有同时满足以下条件，问题 2 的最终区域配置才能进入定稿：

1. 最终输出方案满足所有区域覆盖率 \(\ge90\%\)、服务能力、快充结构、整数与上界约束；
2. 最终方案通过局部邻域支配扫描，不存在严格支配的可行邻域替代；
3. 最终推荐方案来自修复、去重和重新非支配筛选后的候选集；
4. M-A/M-B 的选择基于统一原始指标，而非跨模型比较 TOPSIS 贴近度；
5. TOPSIS 权重敏感性已报告，且结论的稳健性边界已明确；
6. 报告明确目标 3 为“新增接入容量压力”代理指标，不混同为实际分时电网负荷均衡。
