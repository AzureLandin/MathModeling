# 问题4：计算结果制图任务单

> **用途**：本任务单用于指导问题4的图件生成。图件服务于风险演化识别、滚动优化验证和最终建议表达。所有图必须从问题4结果表自动读取数据生成，不允许手工录入或修改数据点。
>
> **模型边界说明**：问题4采用年度整体服务风险与峰时风险投影，不重新模拟未来逐时 24 小时负荷曲线。因此图中必须写“峰时风险率投影”或“最大负荷率年度投影”，不得误标为“未来逐时实际负荷曲线”。

---

## 0. 统一图件规范

### 0.1 文件与目录

建议输出目录：

```text
figures/p4_figures/
```

每个图件导出：

```text
PNG（300 dpi）
PDF（矢量版，论文优先）
```

建议同时输出：

```text
README_图件说明.md
```

每张图在 README 记录：图件编号、源结果表、筛选字段、脚本函数、生成时间、关键核验数值。

### 0.2 字体与主题

中文字体回退顺序：

```text
Microsoft YaHei / SimHei / Noto Sans CJK SC
```

统一配色：

| 元素 | 建议颜色 |
|---|---|
| 2026 | `#4C78A8` 蓝色 |
| 2027 | `#F58518` 橙色 |
| 2028 | `#54A24B` 绿色 |
| 静态基线 S0 | `#7F7F7F` 灰色虚线或浅灰柱 |
| 滚动优化 S1/R-Base | `#1F77B4` 深蓝实线或蓝柱 |
| R-Free 对照 | `#FF7F0E` 橙色 |
| 服务安全 | `#2CA02C` 绿色 |
| 服务/电网预警 | `#FFBF00` 黄色或琥珀色 |
| 服务不足/过载风险 | `#D62728` 红色 |
| 容量阈值 1.0 | 红色虚线 |
| 预警阈值 0.8 | 橙色虚线 |

所有图应具备：标题（预览版）、坐标轴名称与单位、图例、浅网格线。图内不宜堆积长文本，复杂解释放在图注或 README。

### 0.3 通用数据核验

作图前建议在脚本中断言：

1. 年份仅为 `2026, 2027, 2028`；
2. 增长系数依次为：

   \[
   1.15,\quad1.3225,\quad1.520875;
   \]

3. 问题2初始方案全市为 \(634\) 台快充、\(416\) 台慢充；
4. 问题3峰时风险基期值来自补算合并后的最终表；
5. R-Base 滚动方案在各区、各年服务缺口均为 0 或数值容差内为 0；
6. 图中百分比均由原始比例 \(\times100\%\) 得到，防止重复转换。

# 六、验收标准与严谨表述

## 6.1 必须一致的关键数值

图件需能反映且不违背以下计算结果：

- 年增长系数：\(1.15\)、\(1.3225\)、\(1.520875\)；
- 问题2初始新增：634 台快充、416 台慢充；
- 2026 初始地理覆盖率为问题2规划结果，车辆增长本身不使其下降；
- 问题3最终数据必须来自补算合并结果；
- 图中 \(\rho\) 为峰时风险投影；
- 图中 \(\psi\) 为服务保障率，不等于地理覆盖率；
- R-Base 的服务缺口在滚动补桩后应为 0（容差内）。

## 6.2 禁止性表述

图标题、图注、图例和正文引用中禁止出现以下误导：

1. 禁止将峰时风险投影称为“未来每小时实际负荷”；
2. 禁止说“整体需求增长必然导致每小时过载”；
3. 禁止说“新增充电桩自动降低峰时电网负荷”；
4. 禁止将服务保障率误写为地理覆盖率；
5. 禁止把 `R-Free` 的低成本结果不经结构分析直接称为最终推荐方案。

## 6.3 建议的图注口径

对于 P4-F05 和 P4-F06，图注可采用：

> 在日内负荷形态稳定、总体充电负荷随新能源汽车保有量同比例增长的假设下，基于问题3最危险峰时负荷率投影 2026—2028 年容量压力。该图用于年度风险预警，实际工程实施前仍需使用更细粒度逐时数据复核。

对于 P4-F10，图注可采用：

> 滚动补桩仅改善服务供需保障，不被假定为直接改变峰时充电负荷；峰时风险应通过分时电价、预约错峰和配网措施协同治理。
