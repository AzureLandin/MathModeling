# 问题4：计算结果制表任务单

> **用途**：规范问题4的程序结果表导出。这里的“表”是可复算、可制图、可审计的计算结果表，不是论文最终排版表。
>
> **最终数据口径**：问题2使用最终推荐建设方案；问题3必须使用 `results/p3_supplement/` 中补算合并后的最终调度结果。问题4不重新生成未来 24 小时曲线，而输出年度整体服务风险与峰时风险投影结果。

---

## 0. 统一导出要求

建议输出目录：

```text
results/p4_results/
```

每张表同时导出：

```text
.csv
.xlsx
```

并输出：

```text
README_结果表说明.md
```

README 至少记录：输入文件、模型版本、脚本名、增长系数、风险阈值、求解器、生成时间、字段单位。

统一字段约定：

- `区域`：1–10；
- `年份`：2026、2027、2028；
- `增长系数`：1.15、1.3225、1.520875；
- 车次需求与服务能力：`车次/日`；
- 成本：`万元`；
- 桩数：`台`；
- 负荷率、保障率：同时保留 `_raw` 和 `_pct` 两列；
- 风险等级：`安全`、`预警`、`过载风险` 或 `服务安全`、`服务预警`、`服务不足`；
- 所有约束验证使用全精度数值，展示时才四舍五入。


**记录数**：

\[
10\times3=30\text{ 行}.

|---|---|

## P4-T03 年度峰时电网风险投影表

**文件名建议**：

```text
p4_03_峰时电网风险投影.csv/.xlsx
```

**用途**：在不重算未来 24 小时曲线的前提下，投影三年整体峰时压力；对原始负荷与持续 TOU 调度后负荷分别评估。

**记录数**：30 行。

| 字段 | 计算口径 |
|---|---|
| 区域 | 区域编号 |
| 年份 | 2026/2027/2028 |
| 增长系数 | \(g_k\) |
| 基期原始最大负荷率_raw | \(\rho_{i,0}^{raw}\) |
| 预测原始峰时负荷率_raw/pct | \(\rho_{i,k}^{raw}=\rho_{i,0}^{raw}g_k\) |
| 原始峰时风险等级 | <0.8 安全；[0.8,1) 预警；≥1 过载风险 |
| 基期TOU后最大负荷率_raw | \(\rho_{i,0}^{tou}\) |
| 预测TOU后峰时负荷率_raw/pct | \(\rho_{i,k}^{tou}=\rho_{i,0}^{tou}g_k\) |
| TOU后风险等级 | 同上 |
| TOU峰时缓解量_raw/pct | \(\rho_{i,k}^{raw}-\rho_{i,k}^{tou}\) |
| TOU后相对容量裕度_raw/pct | \(1-\rho_{i,k}^{tou}\) |
| 首次原始预警年份 | 首次 \(\rho^{raw}\ge0.8\) |
| 首次原始过载年份 | 首次 \(\rho^{raw}\ge1\) |
| 首次TOU后预警年份 | 首次 \(\rho^{tou}\ge0.8\) |
| 首次TOU后过载年份 | 首次 \(\rho^{tou}\ge1\) |

**重要说明列**：新增 `风险口径说明`，固定填写：

```text
基于问题3最危险峰时负荷率的年度同比投影，不代表未来逐时曲线精确仿真。
```

## P4-T09 优先治理区域排序表

**文件名建议**：

```text

```

排序规则建议按以下字典序执行：

1. `TOU后过载风险` 优先于 `TOU后预警`，优先于 `安全`；

3. 再按 TOU 后峰时负荷率降序；
4. 再按 S0 服务缺口降序；
5. 最后按当年新增投资降序。

## 最终核验清单

- [ ] 需求年增长率严格为 15%；
- [ ] 2026 初始桩数严格承接问题2最终方案；
- [ ] 静态 S0 情景在 2026—2028 不增加设施；
- [ ] 基期最大负荷率来自问题3补算合并最终结果；
- [ ] 电网风险明确标注为“峰时风险投影”，不写成未来逐时精确仿真；
- [ ] R-Base 在每个区域、每年服务能力均不低于预测需求；
- [ ] 输出 R-Free 对照，检验是否产生新增全慢充退化；
- [ ] 快慢充新增数均为非负整数；
- [ ] 所有表均可从 P4-T01 至 P4-T04 的底层数据复算；
- [ ] 不把服务保障率误称为地理覆盖率。
