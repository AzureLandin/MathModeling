# 问题 2：新增快、慢充桩多目标规划

## 1. 问题重述

在既有公共充电桩网络基础上，针对城市主城区 10 个典型区域，规划下一年度新增快充桩和慢充桩数量。规划需同时兼顾：

1. 新增建设成本尽可能低；
2. 公共充电服务覆盖率尽可能高，并满足各区域覆盖率不低于 \(90\%\) 的底线要求；
3. 避免新增大功率充电设施过度集中接入电网容量较紧张的区域，降低区域新增接入容量压力；
4. 满足预测充电车次需求，且不削弱区域既有快充服务结构。

根据问题 1 的结论，2025 年为基准期，下一规划年度采用新能源汽车保有量增长 \(15\%\) 的基准情景。由于附件中覆盖面积、既有桩数、充电需求和电网容量均按区域给出，本题采用“**区域约束 + 全市联合多目标优化**”的规划框架。

---

## 2. 数据、符号与基本假设

### 2.1 符号说明

设区域集合为：

\[
\mathcal I=\{1,2,\ldots,10\}.
\]

对区域 \(i\in\mathcal I\)，定义：

| 符号 | 含义 | 单位 |
|---|---|---|
| \(x_i\) | 新增快充桩数量 | 台 |
| \(y_i\) | 新增慢充桩数量 | 台 |
| \(A_i\) | 区域总面积 | \(\mathrm{km^2}\) |
| \(A_i^{(0)}\) | 既有充电覆盖面积 | \(\mathrm{km^2}\) |
| \(F_i^{(0)}\) | 既有快充桩数量 | 台 |
| \(S_i^{(0)}\) | 既有慢充桩数量 | 台 |
| \(N_i^{(0)}\) | 既有总桩数，\(F_i^{(0)}+S_i^{(0)}\) | 台 |
| \(Q_i^{\mathrm{plan}}\) | 下一规划年度日均充电车次需求 | 车次/日 |
| \(G_i\) | 区域电网总容量 | \(\mathrm{kW}\) |
| \(a_i\) | 区域单桩有效覆盖面积 | \(\mathrm{km^2}/\text{台}\) |
| \(\theta_i\) | 区域既有快充占比 | — |
| \(\nu_i\) | 区域新增接入容量压力率 | — |

决策变量均为非负整数：

\[
\boxed{x_i,y_i\in\mathbb Z_{\geq0}.}
\]

### 2.2 参数设定

由附件 5 可得：

\[
c_f=6\quad \text{万元/台},
\qquad
c_s=0.8\quad \text{万元/台},
\]

\[
p_f=120\quad \mathrm{kW/台},
\qquad
p_s=7\quad \mathrm{kW/台},
\]

\[
s_f=80\quad \text{车次/(台·日)},
\qquad
s_s=20\quad \text{车次/(台·日)}.
\]

附件 1 中区域电网总容量以“万千瓦”为单位，因此换算为：

\[
G_i=10^4g_i,
\]

其中 \(g_i\) 为附件表中的原始数值。

### 2.3 基本假设

1. 下一规划年度内，区域人口密度、车流量、商业 POI 等空间属性保持相对稳定；新能源汽车保有量增长 \(15\%\)，新增车辆在各区域间的分布比例、单车公共充电频率与单次充电量不变。
2. 由于未提供桩位坐标、道路网络及服务半径重叠关系，新增桩优先布设于未覆盖区域，且其平均有效覆盖效率与本区域既有网络相同。
3. 快充与慢充的服务结构不低于区域现状，避免模型因慢充成本较低而退化为全部新增慢充。
4. 新增桩数量不能直接改变用户分时充电行为；日内削峰填谷由问题 3 的分时电价调度解决。因此，本题的电网目标定义为**新增充电设施接入容量压力**，而非实际日内峰谷差。

## 3. 规划需求与覆盖参数计算

### 3.1 充电车次需求预测

附件 5 的单桩服务能力以车次/日给出，故服务能力约束使用附件 2 的充电车次数据。

先计算 2025 年加权日均充电车次：

\[
Q_{i,2025}
=
\frac{5Q_i^{\mathrm{wd}}+2Q_i^{\mathrm{we}}}{7},
\]

其中 \(Q_i^{\mathrm{wd}}\)、\(Q_i^{\mathrm{we}}\) 分别为区域 \(i\) 的工作日、周末全天充电车次。

采用新能源汽车保有量年增长 \(15\%\) 的基准情景，得到下一规划年度需求：

\[
\boxed{
Q_i^{\mathrm{plan}}=1.15Q_{i,2025}.
}
\]

### 3.2 覆盖效率校准

区域具体站点位置未知，无法直接计算服务半径圆的空间并集。因此，用既有网络反推区域平均单桩有效覆盖面积：

\[
\boxed{
a_i=\frac{A_i^{(0)}}{N_i^{(0)}}.
}
\]

该参数已综合反映该区域服务半径、道路网络、桩位重叠、地理阻隔等因素。新增后区域覆盖率近似为：

\[
C_i=
\min\left\{
1,
\frac{A_i^{(0)}+a_i(x_i+y_i)}{A_i}
\right\}.
\]

全市面积加权覆盖率定义为：

\[
C_{\mathrm{city}}
=
\frac{\sum_{i=1}^{10}A_iC_i}{\sum_{i=1}^{10}A_i}.
\]

### 3.3 快充结构基准

定义区域既有快充占比：

\[
\theta_i
=
\frac{F_i^{(0)}}{F_i^{(0)}+S_i^{(0)}}.
\]

该比例约为 \(60\%\)，但模型不将其强行设为统一常数，而是依据各区域现有结构分别约束。

## 4. 多目标整数规划模型

### 4.1 目标 1：新增建设成本最小

\[
\boxed{
\min f_1
=
\sum_{i=1}^{10}
(6x_i+0.8y_i).
}
\]

其中 \(f_1\) 的单位为万元。

### 4.2 目标 2：全市服务覆盖率最大

\[
\boxed{
\max f_2=C_{\mathrm{city}}.
}
\]

在 NSGA-II 最小化框架中，以 \(-C_{\mathrm{city}}\) 作为第二目标。

### 4.3 目标 3：新增接入容量压力最小

新增设施的额定接入功率为：

\[
P_i^{\mathrm{add}}=120x_i+7y_i.
\]

相对于区域电网总容量的新增接入容量压力率定义为：

\[
\boxed{
\nu_i=\frac{120x_i+7y_i}{G_i}.
}
\]

针对“电网负荷均衡性”的不同理解，构建两种候选目标。

#### 模型 M-A：压力平方和

\[
\boxed{
\min f_3^{(A)}
=
\sum_{i=1}^{10}\nu_i^2.
}
\]

该目标同时惩罚总体新增压力偏高和局部压力过度集中。

#### 模型 M-B：压力方差

\[
\bar\nu=\frac{1}{10}\sum_{i=1}^{10}\nu_i,
\]

\[
\boxed{
\min f_3^{(B)}
=
\frac{1}{10}
\sum_{i=1}^{10}(\nu_i-\bar\nu)^2.
}
\]

该目标强调区域间压力分布的均匀性，但不直接抑制总体平均压力。两种目标的关系为：

\[
\sum_{i=1}^{10}\nu_i^2
=
10\operatorname{Var}(\nu_i)+10\bar\nu^2.
\]

因此，平方和目标比单纯方差目标多控制了总体压力水平。

### 4.4 约束条件

#### （1）区域覆盖率下限

\[
\boxed{
A_i^{(0)}+a_i(x_i+y_i)
\ge0.9A_i,
\qquad i\in\mathcal I.
}
\]

#### （2）日服务能力约束

\[
\boxed{
80(F_i^{(0)}+x_i)+20(S_i^{(0)}+y_i)
\ge Q_i^{\mathrm{plan}},
\qquad i\in\mathcal I.
}
\]

#### （3）快充服务结构不退化约束

新增后快充占比不低于既有水平：

\[
\frac{F_i^{(0)}+x_i}
{F_i^{(0)}+S_i^{(0)}+x_i+y_i}
\ge\theta_i.
\]

等价为线性形式：

\[
\boxed{
S_i^{(0)}x_i\ge F_i^{(0)}y_i,
\qquad i\in\mathcal I.
}
\]

#### （4）整数非负及覆盖上界约束

\[
x_i,y_i\in\mathbb Z_{\ge0}.
\]

为避免超出 \(100\%\) 覆盖后仍无意义扩建，令：

\[
n_i^{100}=
\left\lceil
\frac{A_i-A_i^{(0)}}{a_i}
\right\rceil,
\]

并限制：

\[
0\le x_i+y_i\le n_i^{100}.
\]

### 4.5 电网逐时安全预检查

设问题 1 得到的综合典型日分时充电量为：

\[
E_{i,t}^{*}
=
\frac{5E_{i,t}^{\mathrm{wd}}+2E_{i,t}^{\mathrm{we}}}{7}.
\]

下一规划年度预测负荷为：

\[
L_{i,t}^{\mathrm{plan}}=1.15E_{i,t}^{*}.
\]

因 \(\Delta t=1\ \mathrm{h}\)，将其数值作为对应小时平均功率近似，预先检查：

\[
L_{i,t}^{\mathrm{plan}}
\le L_{i,t}^{\max},
\qquad \forall i,t.
\]

全部区域均未越限；其中区域 9 最大负荷率为 \(0.5882\)，最小安全裕度为 \(912.51\ \mathrm{kW}\)，为后续长期扩张中需优先监测的区域。该预检查不随 \(x_i,y_i\) 改变，故不作为 NSGA-II 的动态约束。

## 5. 求解方法：NSGA-II、Pareto 修复与熵权-TOPSIS

### 5.1 NSGA-II 生成 Pareto 候选方案

每个个体编码为：

\[
\boldsymbol z=(x_1,y_1,\ldots,x_{10},y_{10}),
\]

共 20 个整数变量。对 M-A、M-B 分别进行 NSGA-II 多目标优化，使用相同的约束、种群规模、迭代代数和随机种子。

采用 5 个随机种子重复运行，以检验算法随机稳定性。每次运行种群规模为 240，最大迭代 500 代，实际均在第 417 代满足稳定终止条件。

### 5.2 最小快充结构修复

初版遗传搜索中发现部分候选解快充数量高于满足服务结构所需的最小值，导致同覆盖条件下存在成本和接入压力均更低的支配方案。

对给定新增总桩数：

\[
n_i=x_i+y_i,
\]

满足快充结构约束的最小快充数为：

\[
\boxed{
x_i^{\min}(n_i)=\lceil\theta_i n_i\rceil,}
\]

\[
y_i^{\min}(n_i)=n_i-x_i^{\min}(n_i).
\]

若该组合服务能力不足，则逐步将慢充替换为快充；若全部替换仍不足，再增加新增总桩数。修复后重新计算全部目标并进行全局非支配筛选。

该步骤消除了初版方案中区域 3 的冗余快充：

\[
(11,5)\longrightarrow(10,6).
\]

其覆盖率保持 \(90.27\%\)，但区域建设成本由 \(70.0\) 万元降至 \(64.8\) 万元，新增接入功率由 \(1355\ \mathrm{kW}\) 降至 \(1242\ \mathrm{kW}\)。

### 5.3 邻域支配扫描

对修复后的候选方案，逐区域搜索：

\[
(x_i+\Delta x,y_i+\Delta y),
\qquad
\Delta x,\Delta y\in\{-1,0,1\},
\]

检查是否存在满足全部约束且在成本、覆盖率、目标 3 上严格支配当前方案的可行邻域点。最终 M-A 和 M-B 推荐方案均通过邻域支配扫描。

### 5.4 熵权-TOPSIS 择优

对每个模型修复后的 Pareto 集，以：

\[
[f_1,\ C_{\mathrm{city}},\ f_3]
\]

构造评价矩阵，其中成本和目标 3 为成本型指标，覆盖率为效益型指标。利用熵权法确定候选解集内部的客观权重，再由 TOPSIS 计算方案与正理想解的贴近度，选择贴近度最大的方案。

此外，采用等权 TOPSIS 和偏成本权重：

\[
(0.50,0.25,0.25)
\]

进行敏感性检验。M-A 下三类权重对应方案的成本差异不超过 \(2.2\%\)，平均压力差异不超过 \(0.0006\)，表明推荐方案在指标意义上具有较好稳健性。

---

## 6. M-A 与 M-B 的对比及模型选择

修复后，两种压力目标下熵权-TOPSIS 推荐方案的统一比较如下：

| 指标 | M-A：压力平方和 | M-B：压力方差 |
|---|---:|---:|
| 总建设成本/万元 | **4136.80** | 4579.20 |
| 全市面积加权覆盖率 | 90.61% | **92.88%** |
| 平均接入压力 \(\bar\nu\) | **0.0367** | 0.0396 |
| 最大接入压力 \(\nu_{\max}\) | 0.1132 | 0.1132 |
| 压力标准差 \(\sigma_\nu\) | 0.0344 | **0.0322** |
| 压力平方和 | **0.0254** | 0.0261 |
| 压力方差 | 0.0012 | **0.0010** |

M-B 虽然降低了区域压力标准差，但其建设成本相较 M-A 增加：

\[
\frac{4579.20-4136.80}{4136.80}
=10.7\%.
\]

同时，平均新增接入压力上升，而最大压力并未下降。因此，M-B 的均衡效果主要来自向低压力区域增加建设，属于“总体压力更高但分布更均匀”的伪均衡情形。

故最终选用 M-A：

\[
\boxed{
\min f_3
=
\sum_{i=1}^{10}
\left(
\frac{120x_i+7y_i}{G_i}
\right)^2.
}
\]

该目标能够同时控制总体接入压力和局部集中风险，且具有更低成本和更好的稳健性。

## 8. 约束验证

最终方案对所有区域均满足：

\[
C_i\ge90\%,
\]

\[
80(F_i^{(0)}+x_i)+20(S_i^{(0)}+y_i)
\ge Q_i^{\mathrm{plan}},
\]

\[
S_i^{(0)}x_i\ge F_i^{(0)}y_i,
\]

以及非负整数和 \(100\%\) 覆盖上界约束。

同时，下一规划年度预测分时负荷均未超过附件 4 的逐时电网最大允许负荷。最终方案已通过结构修复和 \(\pm1\) 离散邻域支配扫描，不存在严格支配的可行邻域替代方案。

## 9. 模型评价

### 9.1 优点

1. 同时考虑成本、整体覆盖质量与区域新增接入容量压力，符合公共充电网络规划的多目标特征；
2. 覆盖率、服务能力和快慢充结构均按区域设置硬约束，保障服务公平性和区域差异；
3. 使用面积加权覆盖率，避免大面积城郊区域在整体评价中被忽略；
4. 采用 NSGA-II 输出多目标 Pareto 候选集，避免事先主观设定目标权重；
5. 通过最小快充结构修复和邻域支配扫描，消除了遗传算法搜索中出现的冗余快充与局部劣解；
6. 通过熵权、等权、偏成本 TOPSIS 对照，验证最终 M-A 方案对评价权重具有较好的指标稳健性。

### 9.2 局限性

1. 未提供候选站点坐标、道路网络、土地可用性及配电接入点，覆盖模型只能以既有网络平均有效覆盖效率近似；
2. \(\nu_i\) 为新增设施额定接入容量压力率，未引入同时率和利用率，不能替代实际运行功率潮流计算；
3. NSGA-II 为有限随机搜索，修复后的 Pareto 集是已搜索候选方案上的严格非支配集，不能声称为理论全局 Pareto 前沿；
4. 单桩服务能力采用题设固定值，未进一步区分快充、慢充用户偏好、停车时长与排队行为；
5. 本方案以 2026 年 \(15\%\) 基准增长情景规划，未来若出现人口导入、交通枢纽建设或商圈扩张，应根据问题 1 的需求潜势模型及新数据滚动更新。

---

## 10. 问题 2 结论

在 2026 年新能源汽车保有量增长 \(15\%\) 的基准情景下，采用“区域覆盖与服务硬约束 + 全市多目标整数优化”的方法，最终建议新增：

\[
\boxed{634\ \text{台快充桩},\qquad416\ \text{台慢充桩}.}
\]

总新增数量为：

\[
\boxed{1050\ \text{台}},
\]

总投资为：

\[
\boxed{4136.80\ \text{万元}}.
\]

方案将全市面积加权服务覆盖率提高至：

\[
\boxed{90.61\%},
\]

并确保所有区域覆盖率不低于 \(90\%\)、服务能力满足预测需求、快充服务结构不退化。与单纯最小化区域接入压力方差的方案相比，压力平方和模型以较低投资成本和较低平均新增接入压力获得了更稳健的综合配置结果。
