# 问题1—问题3：计算结果制图任务单

> **用途**：本任务单用于指导编程手将问题 1、问题 2、问题 3 的计算结果转化为可复核、可直接用于论文排版的图件。图件首先服务于结果诊断与模型验证，论文定稿时再择优选用。
>
> **数据原则**：所有图件必须由结果表自动读取和生成，禁止手工修改数据点或手动标注数值。问题 3 必须使用补算合并后的最终数据；问题 2 的最终推荐方案必须来自 Pareto 修复后、熵权—TOPSIS 选出的方案。

---

## 0. 图件通用规范

### 0.1 目录结构与文件格式

建议目录：

```text
figures/
├─ p1_figures/
├─ p2_figures/
└─ p3_figures/
```

每张图至少导出：

```text
PNG  （用于快速预览与 Markdown）
PDF  （论文矢量排版优先）
SVG  （如字体、图例兼容则额外导出）
```

默认分辨率：

```text
PNG: dpi = 300
```

单图尺寸建议：

| 图类型 | 尺寸（英寸） |
|---|---|
| 单变量柱状图、散点图 | 8 × 5 |
| 双面板或双子图 | 12 × 5 |
| 10 区域分面图 | 15 × 10 |
| 24 小时曲线图 | 10 × 5.5 |
| Pareto 三维图 | 9 × 7 |

### 0.2 中文字体与数学字体

建议按运行环境配置下列字体回退顺序：

```text
Microsoft YaHei / SimHei / Noto Sans CJK SC
```

- 负号必须正常显示；
- 坐标轴单位必须写入；
- 公式变量优先使用 LaTeX 数学格式；
- 图名可不写在图内，便于论文使用 `\caption{}` 单独排版；若生成预览图，图内标题应简洁。

### 0.3 色彩、线型和可读性

统一主题（建议色盲友好）：

| 元素 | 推荐颜色 | 说明 |
|---|---|---|
| 工作日 | `#1F77B4` 蓝色 | 主要曲线 |
| 周末 | `#FF7F0E` 橙色 | 对照曲线 |
| 调度前 | `#7F7F7F` 灰色虚线 | 基线 |
| 调度后 | `#1F77B4` 或 `#2CA02C` 实线 | 优化结果 |
| 最大允许负荷 | `#D62728` 红色点划线 | 安全边界 |
| 高峰背景 | 浅红色，alpha≈0.10 | \(\mathcal H\) |
| 平段背景 | 浅黄色，alpha≈0.08 | \(\mathcal M\) |
| 低谷背景 | 浅蓝色，alpha≈0.10 | \(\mathcal V\) |
| 推荐解 | `#E31A1C` 红色大点/星形 | Pareto 图突出 |

通用要求：

1. 不使用仅靠红绿区分的信息表达；
2. 所有曲线图均显示网格线（浅灰色）；
3. 需要标出关键极值、阈值或推荐解时，使用箭头或文字标签，避免堆叠；
4. 图例位置优先 `best`，若遮挡曲线则置于图外右侧；
5. 区域编号一律使用 `区域1` 至 `区域10`，排序图可只用数字 `1` 至 `10`，但图注中应说明。

### 0.4 结果一致性检查

作图脚本运行前后应核验：

- 图中数据行数与结果表记录数一致；
- 排序图是否按指定排序排序；
- 百分数值是否从原始比例正确转换；
- 24 小时曲线横轴是否严格为 `00:00-01:00` 至 `23:00-00:00`；
- 问题 3 是否采用 `p3_supplement` 的合并最终结果；
- 每张图的源数据文件和生成脚本都记录在图件 README 中。

建议在各图件目录生成：

```text
README_图件说明.md
```

写明图号、用途、源结果表、筛选条件、脚本名、生成时间。
