# 问题3：二阶段方差优化补充验证任务单

> **触发原因**：问题三的第一阶段线性规划（最小化调度后峰谷差）已在 20 个“区域 × 日期类型”子问题中全部求得最优解，并通过电量守恒与逐时电网安全核验；但第二阶段凸二次规划在其中 5 个子问题中因 SLSQP 的 `Positive directional derivative for linesearch` 返回而回退为第一阶段 LP 解。回退解保持峰谷差主目标最优，但尚不能证明其调度后方差最小。本任务只对这 5 个回退子问题进行稳健补算。

---

## 1. 补算目的与边界

### 1.1 目的

对第一阶段峰谷差最优解集进行严格的凸二次规划求解，获得其中**全天负荷方差最小**的低谷分配方案，从而使最终 24 小时调度曲线具有唯一、可复现且可解释的字典序最优性：

\[
\boxed{\text{先最小化峰谷差；再在峰谷差最优解集中最小化全天负荷方差。}}
\]

### 1.2 不重新计算的内容

本补算**不得改变**下列已确认部分：

1. 峰、平、谷时段划分；
2. 高峰转移比例 \(20\%\)；
3. 高峰时段按 \(0.8\) 系数削减、平段及 \(23{:}00\text{--}00{:}00\) 保持不变的规则；
4. 第一阶段 LP 已得到的最优峰谷差 \(\Delta_{i}^{d,*}\)；
5. 电量守恒和附件 4 逐时最大允许负荷约束。

补算仅可能改变低谷 7 小时的分配向量 \(\boldsymbol z_i^d\)、调度后方差和相应曲线的局部形态；不应恶化主目标最优值。

## 2. 时段与符号口径（定稿）

### 2.1 题设固定时段

高峰时段为：

\[
\mathcal H=
\{11\!:\!00\text{--}12\!:\!00,
12\!:\!00\text{--}13\!:\!00,
13\!:\!00\text{--}14\!:\!00,
16\!:\!00\text{--}17\!:\!00,
\ldots,
22\!:\!00\text{--}23\!:\!00\},
\]

故：

\[
\boxed{|\mathcal H|=10}.
\]

低谷时段为：

\[
\mathcal V=
\{00\!:\!00\text{--}01\!:\!00,
\ldots,
06\!:\!00\text{--}07\!:\!00\},
\qquad |\mathcal V|=7.
\]

题设未明确归类的 \(23{:}00\text{--}00{:}00\) 时段按原模型处理为**固定、不参与转移**时段：

\[
\widetilde L_{i,23}^{d}=L_{i,23}^{d}.
\]

### 2.2 符号

对区域 \(i\in\{1,\ldots,10\}\)、日期类型 \(d\in\{\mathrm{wd},\mathrm{we}\}\)、时段 \(t\in\{1,\ldots,24\}\)：

| 符号 | 含义 | 单位 |
|---|---|---|
| \(L_{i,t}^{d}\) | 调度前小时平均充电负荷 | \(\mathrm{kW}\) |
| \(G_{i,t}\) | 电网最大允许负荷 | \(\mathrm{kW}\) |
| \(M_i^d\) | 高峰转移总量 | \(\mathrm{kWh/day}\) 或等价的小时分配增量之和 |
| \(z_{i,t}^{d}\) | 分配至低谷时段 \(t\) 的转移量 | \(\mathrm{kW}\) |
| \(\widetilde L_{i,t}^{d}\) | 调度后小时平均负荷 | \(\mathrm{kW}\) |
| \(\Delta_i^{d,*}\) | 第一阶段已求得的最优峰谷差 | \(\mathrm{kW}\) |
| \(U_i^d,V_i^d\) | 调度后负荷的最大/最小上界辅助变量 | \(\mathrm{kW}\) |

## 4. 固定的第一阶段结果与调度关系

### 4.1 高峰转移总量

\[
M_i^d=0.2\sum_{t\in\mathcal H}L_{i,t}^{d}.
\]

### 4.2 调度后曲线

\[
\widetilde L_{i,t}^{d}=
\begin{cases}
0.8L_{i,t}^{d}, & t\in\mathcal H,\\[4pt]
L_{i,t}^{d}+z_{i,t}^{d}, & t\in\mathcal V,\\[4pt]
L_{i,t}^{d}, & t\notin\mathcal H\cup\mathcal V.
\end{cases}
\]

其中：

\[
\sum_{t\in\mathcal V}z_{i,t}^{d}=M_i^d.
\]

并以第一阶段已保存的 \(\Delta_i^{d,*}\) 为固定最优界。若数据文件未保存该值，可重新运行第一阶段 LP **仅用于复现 \(\Delta_i^{d,*}\)**，但不得修改其模型或容差口径。

## 5. 第二阶段严格凸二次规划模型

### 5.1 目标函数

全天平均负荷由电量守恒确定：

\[
\bar L_i^d=\frac{1}{24}\sum_{t=1}^{24}L_{i,t}^{d}.
\]

在第一阶段最优峰谷差解集中，求解：

\[
\min_{\boldsymbol z,U,V}
\quad
J_i^d=
\frac{1}{24}\sum_{t=1}^{24}
\left(
\widetilde L_{i,t}^{d}-\bar L_i^d
\right)^2.
\]

### 5.2 约束条件

**（1）转移电量守恒）**

\[
\sum_{t\in\mathcal V}z_{i,t}^{d}=M_i^d.
\]

**（2）低谷分配非负与容量上界）**

\[
0\le z_{i,t}^{d}
\le G_{i,t}-L_{i,t}^{d},
\qquad t\in\mathcal V.
\]

若某个上界因数据导致小于零，应先标记基线越限；不得将其直接截断后仍声称原始负荷安全。

**（3）线性化峰谷差最优性保持）**

对所有 \(t\in\mathcal T\)：

\[
V_i^d\le\widetilde L_{i,t}^{d}\le U_i^d.
\]

并强制：

\[
U_i^d-V_i^d\le\Delta_i^{d,*}+\epsilon_\Delta,
\]

推荐：

\[
\epsilon_\Delta=10^{-6}\ \mathrm{kW}.
\]

如果受浮点精度影响使模型被误判为不可行，可按顺序仅测试：

\[
10^{-6}\rightarrow10^{-5}\rightarrow10^{-4},
\]

并在结果中记录最终采用的 \(\epsilon_\Delta\)。不得直接放宽至影响保留第一阶段最优性的量级。

**（4）逐时电网容量约束）**

\[
\widetilde L_{i,t}^{d}\le G_{i,t},
\qquad t\in\mathcal T.
\]

对高峰与固定时段，此约束在第二阶段无自由度但仍应复核；对低谷时段，该约束已由 \(z\) 的上界体现。

## 6. 推荐求解方案与实施顺序

### 6.1 首选：CVXPY + CLARABEL / OSQP

本问题为凸二次规划：目标函数是凸二次函数，约束均为仿射约束与区间约束。建议优先使用 `cvxpy`。

```python
import cvxpy as cp

z = cp.Variable(7, nonneg=True)
U = cp.Variable()
V = cp.Variable()

# 构造 L_post（高峰、固定时段为常数；谷段为 L_valley + z）
objective = cp.Minimize(cp.sum_squares(L_post - L_mean) / 24)
constraints = [
    cp.sum(z) == M,
    z <= valley_capacity,
    L_post <= U,
    L_post >= V,
    U - V <= delta_star + eps_delta,
    L_post <= G,
]
problem = cp.Problem(objective, constraints)
problem.solve(solver=cp.CLARABEL)  # 首选
```

若 `CLARABEL` 不可用，则尝试：

```python
problem.solve(solver=cp.OSQP, eps_abs=1e-8, eps_rel=1e-8, polish=True)
```

### 6.2 备选：显式消去辅助变量后的低维凸优化

若没有 `cvxpy`，可采用 `scipy.optimize.minimize(method='trust-constr')`。建议只将 \(z\in\mathbb R^7\) 作为变量，直接将每个小时的线性负荷表达写入约束；不要使用原 SLSQP 失败时的起点和参数配置。

可采用第一阶段 LP 解作为初始点，且必须验证最终约束违反量。

### 6.3 不建议的处理

- 不得在二阶段失败后直接将 LP 解标注为“方差最优”；
- 不得改变峰、平、谷时段或将剩余负荷转入平段；
- 不得修改 \(20\%\) 转移比例；
- 不得因求解方便放松电量守恒、电网容量或第一阶段最优峰谷差界；
- 不得用四舍五入后的 \(z\) 再参与约束核验；核验必须基于全精度结果。

## 7. 结果核验（全部必须通过）

对每一个成功补算对象，设求解后的低谷分配为 \(\widehat z_{i,t}^{d}\)，必须输出下列误差：

### 7.1 电量守恒

\[
e_1=
\left|
\sum_{t=1}^{24}\widetilde L_{i,t}^{d}
-
\sum_{t=1}^{24}L_{i,t}^{d}
\right|
<10^{-8}.
\]

### 7.2 转移量闭合

\[
e_2=
\left|
\sum_{t\in\mathcal V}\widehat z_{i,t}^{d}-M_i^d
\right|
<10^{-8}.
\]

### 7.3 安全约束

\[
e_3=
\max_{t\in\mathcal T}
\left(
\widetilde L_{i,t}^{d}-G_{i,t}
\right)
\le10^{-8}.
\]

### 7.4 第一阶段主目标保持

重新计算：

\[
\Delta_i^{d,\mathrm{new}}
=
\max_t\widetilde L_{i,t}^{d}
-
\min_t\widetilde L_{i,t}^{d}.
\]

必须满足：

\[
\Delta_i^{d,\mathrm{new}}
\le\Delta_i^{d,*}+\epsilon_\Delta+10^{-7}.
\]

同时报告：

\[
e_4=\left|\Delta_i^{d,\mathrm{new}}-\Delta_i^{d,*}\right|.
\]

理论上应接近零；若出现明显负值或正值，需复核第一阶段保存精度、\(U,V\) 约束与时段索引。

### 7.5 次目标改进或不劣

设原 LP 回退解方差为 \(J_i^{d,\mathrm{LP}}\)，补算后方差为 \(J_i^{d,\mathrm{QP}}\)，应满足：

\[
J_i^{d,\mathrm{QP}}
\le J_i^{d,\mathrm{LP}}+10^{-8}.
\]

并给出相对改善率：

\[
R_{i,J}^{d}
=
\frac{J_i^{d,\mathrm{LP}}-J_i^{d,\mathrm{QP}}}{J_i^{d,\mathrm{LP}}}
\times100\%.
\]

若两者近似相等，说明原 LP 解碰巧已处于或非常接近次目标最优点；这也是可接受结论，但必须以 QP 最优求解状态证明。
