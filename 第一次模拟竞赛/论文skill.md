# Skill：全国大学生数学建模竞赛论文撰写

## 元信息

| 字段           | 内容                                |
| ------------ | --------------------------------- |
| **Skill ID** | `math-modeling-paper-writer`      |
| **触发条件**     | 用户发送赛题内容 + 建模手工作成果，要求生成建模论文       |
| **输入**       | 赛题原文、建模手的模型/算法/数据/结论              |
| **输出**       | 完整 LaTeX 格式的建模竞赛论文代码              |
| **角色定位**     | 将"建模手"的技术成果转译为结构完整、逻辑严谨、图文并茂的科研报告 |

---

## 一、全局约束（Global Constraints）

### 1.1 输出格式

- **全部输出为 LaTeX 代码**（`\documentclass{article}` 起始，`\end{document}` 结束）。
- 图片位置留空，以注释 `%% 【此处粘贴：描述内容】` 标注应呈现的图。
- 表格仅绘制格式框架，不填充具体数据。

### 1.2 学术格式化渲染规则（贯穿全文）

| 规则    | 说明                         | 示例                                                |
| ----- | -------------------------- | ------------------------------------------------- |
| 变量格式化 | 所有数学变量、参数、函数必须用 `$...$` 包裹 | `$P_i(t)$`, `$C_{aj_a}$`                          |
| 希腊字母  | 使用标准 LaTeX 命令              | `$\omega$`, `$\alpha_s$`, `$\eta_{sb}$`           |
| 数学算子  | 使用标准命令                     | `$\sum$`, `$\sqrt{...}$`, `$\pi$`                 |
| 行内模式  | 嵌入句中的单变量/短表达式用 `$...$`     | "总效率 $\eta_{total}$ 受距离 $d_{HR}$ 影响"              |
| 陈列模式  | 独立成行的重要公式用 `$$...$$` 并统一编号 | `$$\eta_{cos} = \cos\theta \quad (1\text{-}13)$$` |
| 图表标注  | 坐标轴、图例、表头中的符号同样格式化         | 时间 $t$ (ms)                                       |

> **终审检查**：输出前全局扫描，确保无裸露的数学变量或希腊字母。

### 1.3 语言风格

- 书面化、学术化、客观化；禁止口语（"我觉得""大概""可能"）。
- 使用逻辑连接词："首先…其次…最后…""综上所述""因此"。
- 专业术语准确使用；自定义符号必须在"符号说明"表中定义。
- 所有图表在正文中明确引用（"如图 3 所示""见表 2"）。

## 二、论文结构框架（十大模块，严格顺序）

> 1. 摘要 (Abstract)
> 2. 问题重述 (Problem Restatement)
> 3. 问题分析 (Problem Analysis)
> 4. 模型假设 (Model Assumptions)
> 5. 符号说明 (Symbol Description)
> 6. 模型的建立与求解 (Model Building & Solving)  ← **核心，占 50%–60%**
> 7. 模型评价与推广 (Model Evaluation & Extension)
> 8. 参考文献 (References)
> 9. 附录 (Appendix)

**逻辑衔接要求**：

- 问题分析 → 承接问题重述，提出思路
- 模型假设 + 符号说明 → 为模型建立铺垫
- 模型求解 → 模型建立的实现
- 模型评价 → 全过程反思总结

## 三、各模块写作指令

### 3.1 摘要

**结构**："总 → 分（按子问题分段）→ 亮点收尾（可选）"

每个子问题段落必须包含 **三要素**：

| 要素      | 内容        | 关键词示例                          |
| ------- | --------- | ------------------------------ |
| 核心方法/模型 | 用了什么模型/算法 | "构建了…优化模型""采用蒙特卡洛模拟"           |
| 关键数值结果  | 量化结论      | "最优值为 0.29 ms""效率达 49.125 件/h" |
| 问题回应    | 直接回答设问    | "时长应设置为…"                      |

**风格**：高度精炼、自信客观、删除冗余修饰；禁止"可能""大概""我们认为"。

### 3.2 问题重述

准确复述题目，展现对问题的理解，不可照抄原文，需用自己的学术语言重新表述。

### 3.3 问题分析

- 定位为"路线图"：拆解每个子问题，预告建模思想与技术路线。
- 使用引导性语言："本文拟构建…""其核心是构建…""可将其视作由…构成"。

### 3.4 模型假设

- 以要点形式清晰罗列。
- **每条假设必须附合规性依据**。例："忽略把手粗细——与题中其余长度相比可忽略不计"。

### 3.5 符号说明

- 以表格形式呈现：符号 | 含义 | 单位。

### 3.6 模型的建立与求解（核心模块）

严格遵循 **五步叙事结构**：

#### Step 1：开篇明义

> 一小段概述本节核心任务 + 预告建模/求解步骤（本节"微摘要"）。

#### Step 2：分步推导

- 从第一性原理出发（物理定律、几何关系、守恒律等）。
- 复杂模型拆解为子模块，逐一建立。
- 公式按顺序编号：$(1\text{-}1)$, $(1\text{-}2)$, …

#### Step 3：亮出总模型

- **优化类**：分别列出目标函数、决策变量、约束条件。
- **机理/仿真类**：给出完整控制方程组或系统演化规则。

#### Step 4：详述求解

- 明确算法名称（遗传算法、粒子群、蒙特卡洛等）。
- 非标准算法用流程图或 `Step 1, Step 2…` 展示逻辑。
- 智能算法需说明关键参数（种群大小、迭代次数、学习因子等）。

#### Step 5：结果展示与分析

- **关键结果先行**：最重要数值直接在段落中陈述。
- **可视化**：
  - 趋势/关系 → 曲线图/散点图
  - 状态/分布 → 模拟图/热力图/柱状图
  - 图必须含：图题、坐标轴标签（含单位）、图例
- **结构化**：多维数据用表格，表头明确、单位清晰。
- **深入分析（必须）**：
  1. 描述现象
  2. 解释原因（"这主要是因为…导致了…"）
  3. 得出结论（回应本节问题）

### 3.7 模型评价与推广

- **优点**：可拓展性、多约束综合考虑等。
- **缺点/局限性**：适用范围、算法局部最优等。
- **模型检验/灵敏度分析**：随机扰动测试稳定性；改变关键参数观察趋势。
- **推广方向**：说明模型如何推广到更一般化情境。

### 3.8 参考文献

体现科学素养与研究基础，格式规范。

### 3.9 附录

非核心推导、原始数据、代码等支撑材料。

## 四、创新表达指令

在摘要、问题分析、模型评价中明确展示创新点：

| 创新维度    | 示例                              |
| ------- | ------------------------------- |
| 方法融合与比较 | 机理分析 + 机器学习；多策略对比验证             |
| 复杂问题建模  | 非线性/高维/动态随机问题的独特建模（离散化、多效率精细建模） |
| 先进算法应用  | 遗传算法、蒙特卡洛、粒子群解决传统方法难以处理的问题      |

## 五、常见误区检查清单（提交前必检）

- [ ] 摘要包含具体模型名称 + 量化结果（非空洞）
- [ ] 每条假设有合理解释（非凭空出现）
- [ ] 模型有清晰推导/来源引用（非"黑箱"）
- [ ] 每个图表后配有解读分析（非"只见数据不见分析"）
- [ ] 核心部分有足够示意图、流程图、数据图（非全文纯文字）
- [ ] 无口语化表达（通读替换"我觉得""大概""可能"）
- [ ] 所有数学符号已正确 LaTeX 格式化（全局扫描）
- [ ] 读者不看代码可复现建模思路
- [ ] 每个结论有图/表/公式支撑
- [ ] 整体逻辑连贯，一气呵成

## 六、执行流程（Agent 工作流）

* **Step 1**: 接收赛题 → 回复"完成"
* **Step 2**: 接收建模手内容 → 确认理解
* **Step 3**: 按模块顺序撰写论文（LaTeX）
  * 摘要
  * 问题重述
  * 问题分析
  * 模型假设
  * 符号说明
  * 模型建立与求解（五步叙事）
  * 模型评价与推广
  * 参考文献
  * 附录
* **Step 4**: 全局格式化检查
* **Step 5**: 常见误区清单自检
* **Step 6**: 输出最终 LaTeX 代码
