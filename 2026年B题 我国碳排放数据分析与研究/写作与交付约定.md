# 写作与交付约定

> 本文档用于固化当前项目的写作约定，后续会话压缩、续写或修改时均应优先遵守。

## 1. 模板与题目名称

1. 论文唯一排版与章节结构基线为：`E:\MathModeling\Latex模板\mathmodel_template.tex`。
2. 项目按当前目录名称“2026年B题 我国碳排放数据分析与研究”进行组织、命名和交付。
3. 不再核对、讨论或修正题目究竟属于 B 题还是 C 题，也不再核验赛事官方模板；不得在论文中加入相关争议说明。

## 2. 写作结构

1. 正文严格沿用模板主结构：问题重述、问题分析、模型假设、符号说明、模型准备、模型建立与求解、模型的评价与推广、参考文献、附录。
2. 四个任务均放入“模型建立与求解”章节，以“问题一模型建立及求解”至“问题四模型建立及求解”的形式呈现。
3. 不设置独立“结论”章节。
4. 删除或避免工程交付式表述，如“审计、资源绑定、哈希、W1/W2、严格校验、复现门禁”等；附录只保留必要的支撑文件、AI使用说明和关键代码。

## 3. 工作方式

1. 不再执行重型严格检验流程、独立审核流程或赛事规则核验流程。
2. 修改时优先提供及时进展反馈；完成后只进行一次常规 XeLaTeX 编译，确认 LaTeX 文件和 PDF 可正常生成即可。
3. 如需运行 Python，使用 `E:\Anaconda\envs\math_modeling\python.exe`。
4. 保留已经由项目代码生成的真实数值、图表和结果文件；正文不可虚构计算结果。

## 4. 当前目标

以用户指定模板为唯一格式依据，重写并持续优化 `完整论文-LaTeX\main.tex` 的格式、章节层级和竞赛论文表达。


## 模型建立与求解的组织约定（2026-08-23）

- 每一问固定采用“模型建立—模型求解—结果展示”的三段式结构。
- **模型建立**必须说明模型来源（物理/统计规律或经典数学模型）、变量含义、适用理由和全部核心公式。公式使用 `equation` 环境，由 LaTeX 在全文中自动顺序编号。
- **模型求解**必须用 `Step 1、Step 2、Step 3` 展开；每一步写明输入变量、具体计算公式、所用成熟算法或自定义过程及对应输出，不能仅以“采用某方法”概述。
- **结果展示**集中放置图和表。图应提供标题、坐标轴标签、单位与图例，并在图注中说明读图结论；表应给出明确表头和单位。
- 对成熟算法直接点明算法名称（如Moran置换检验、Ward层次聚类、L-BFGS-B约束优化）；对规则或递推过程用逐步公式说明。

- **结果展示**保留题目要求的关键数值、图和表，并在图表后用一段文字给出简要结果分析；不设置独立的“结果分析与验证”栏目。

- “结果展示”中的每张图和每个表之后必须紧跟对应的简要解释，至少说明图表展示对象、关键结果和直接结论；图注不能替代正文解释。

- 每个问题的“结果展示”末尾应补充一段“本问结论”，用简洁文字直接归纳该问的核心发现和题目要求的最终结论。

- 项目代码统一存放于 `完整论文-LaTeX/code`；核心计算按“负责问题 + 功能（英文）”拆分命名，并通过 `All_model_runner.py` 顺序运行。
