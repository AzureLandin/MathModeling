## 图2：Delaunay三角剖分候选边图

### 论文中的作用

放在第一步"数据预处理"段落，说明为什么可以用Delaunay图替代完全图。图中应能直观看到：剖分边都是"自然邻近"的连接，没有明显绕远的交叉边；且MST（可用粗线叠加）完全包含在剖分边中。

### 绘制规格

```python
from scipy.spatial import Delaunay

tri = Delaunay(coords)

fig, ax = plt.subplots(figsize=(10, 9))

# 绘制Delaunay边（浅灰色细线）
edges_plotted = set()
for simplex in tri.simplices:
    for i in range(3):
        for j in range(i+1, 3):
            a, b = simplex[i], simplex[j]
            edge = (min(a,b), max(a,b))
            if edge not in edges_plotted:
                edges_plotted.add(edge)
                ax.plot([coords[a,0], coords[b,0]], 
                        [coords[a,1], coords[b,1]],
                        c='#BDC3C7', linewidth=0.5, zorder=1)

# 叠加全局MST（橙色粗线，证明MST ⊂ Delaunay）
mst_edges = compute_mst_edges(set(range(181)), dist_matrix)
for (u, v) in mst_edges:
    ax.plot([coords[u,0], coords[v,0]], 
            [coords[u,1], coords[v,1]],
            c='#E67E22', linewidth=1.5, alpha=0.8, zorder=2)

# 节点
ax.scatter(coords[1:, 0], coords[1:, 1], c='#3498DB', s=15, zorder=3)
ax.scatter(coords[0, 0], coords[0, 1], c='#E74C3C', s=200, marker='*', zorder=5)

ax.set_title('图2  Delaunay三角剖分与全局MST', fontsize=14)
ax.set_xlabel('X 坐标 (km)', fontsize=12)
ax.set_ylabel('Y 坐标 (km)', fontsize=12)
# 图例：灰线=Delaunay候选边，橙线=全局MST
ax.set_aspect('equal')
ax.grid(True, alpha=0.2)
plt.tight_layout()
plt.savefig('figures/图2_Delaunay三角剖分.png', dpi=300, bbox_inches='tight')
plt.savefig('figures/图2_Delaunay三角剖分.pdf', bbox_inches='tight')
```

### 视觉要求

- Delaunay边用极浅灰色（#BDC3C7）、细线（0.5pt），作为背景纹理
- 全局MST用橙色（#E67E22）、1.5pt粗线叠加，形成对比
- 图例说明"灰色=Delaunay候选边（537条），橙色=全局MST（180条）"
- 论文中配文："可以观察到，MST的所有边均落在Delaunay剖分图内，验证了空间降维的无损性。"

## 图3：约束聚类结果图

### 论文中的作用

放在第二步"空间受限聚类"段落，是论文的核心过程图之一。展示最终簇划分方案：不同簇用不同颜色，一级站用特殊标记，簇边界用凸包或Voronoi暗示。读者应能直观看到每个簇的空间范围合理、形状偏链状。

### 绘制规格

```python
import matplotlib.cm as cm
from scipy.spatial import ConvexHull

fig, ax = plt.subplots(figsize=(11, 10))

# 颜色方案：使用tab20或自定义离散色板
cmap = cm.get_cmap('tab20', len(clusters))

for k, cluster in enumerate(clusters):
    nodes = list(cluster)
    color = cmap(k)
    
    # 簇内节点
    ax.scatter(coords[nodes, 0], coords[nodes, 1], 
               c=[color], s=40, zorder=3, edgecolors='white', linewidths=0.5)
    
    # 簇内MST边（细线）
    for (u, v) in cluster_mst_edges[k]:
        ax.plot([coords[u,0], coords[v,0]], 
                [coords[u,1], coords[v,1]],
                c=color, linewidth=1.0, alpha=0.7, zorder=2)
    
    # 凸包边界（虚线）
    if len(nodes) >= 3:
        hull = ConvexHull(coords[nodes])
        hull_pts = coords[nodes][hull.vertices]
        hull_pts = np.vstack([hull_pts, hull_pts[0]])  # 闭合
        ax.plot(hull_pts[:, 0], hull_pts[:, 1], 
                '--', c=color, linewidth=1.2, alpha=0.5, zorder=1)
    
    # 一级站：黑色方块标记
    ps = primary_stations[k]
    ax.scatter(coords[ps, 0], coords[ps, 1], 
               c='black', s=120, marker='s', zorder=5, edgecolors='white', linewidths=1.5)
    
    # 簇编号标注（质心位置）
    centroid = coords[nodes].mean(axis=0)
    ax.annotate(f'C{k+1}\n({cluster_mst_lengths[k]:.1f}km)', 
                xy=centroid, fontsize=8, ha='center', color=color, fontweight='bold')

# 中心站A
ax.scatter(coords[0, 0], coords[0, 1], c='#E74C3C', s=300, marker='*', zorder=6)
ax.annotate('A', xy=(26, 31), xytext=(27, 29), fontsize=12, fontweight='bold', color='#E74C3C')

ax.set_title('图3  约束凝聚聚类结果（各簇MST长度标注）', fontsize=14)
ax.set_xlabel('X 坐标 (km)', fontsize=12)
ax.set_ylabel('Y 坐标 (km)', fontsize=12)
# 图例：方块=一级站，红星=中心站A，虚线=簇边界
ax.set_aspect('equal')
ax.grid(True, alpha=0.2)
plt.tight_layout()
plt.savefig('figures/图3_聚类结果.png', dpi=300, bbox_inches='tight')
plt.savefig('figures/图3_聚类结果.pdf', bbox_inches='tight')
```

### 视觉要求

- 每个簇一种颜色，颜色区分度高（避免相邻簇颜色相近）
- 一级站用黑色实心方块（■），与二级站的彩色圆点明确区分
- 簇内MST边用该簇颜色绘制，线宽1pt
- 凸包用虚线，透明度0.5，仅暗示范围不喧宾夺主
- 每个簇标注编号和MST长度（如"C3 (24.7km)"），方便论文引用
- 中心站A红星始终在最上层

## 图7：模拟退火收敛曲线

### 论文中的作用

放在第五步"局部搜索优化"段落，展示SA算法的收敛过程。X轴为迭代次数，Y轴为目标函数值（总费用）。应能看到：初始阶段快速下降（高温探索），中期阶梯式下降（发现更优解），后期趋于平稳（收敛）。

### 绘制规格

```python
fig, ax = plt.subplots(figsize=(10, 5.5))

# convergence_curve: 每次改善时的 (iteration, C_total) 记录
iterations = [item[0] for item in convergence_curve]
costs = [item[1] / 10000 for item in convergence_curve]  # 转为万元

ax.plot(iterations, costs, c='#2C3E50', linewidth=1.5)

# 标注初始解和最终解
ax.scatter([0], [costs[0]], c='#E74C3C', s=80, zorder=5, label=f'初始解: {costs[0]:.2f} 万元')
ax.scatter([iterations[-1]], [costs[-1]], c='#27AE60', s=80, zorder=5, label=f'最优解: {costs[-1]:.2f} 万元')

# 标注改善幅度
improvement = (costs[0] - costs[-1]) / costs[0] * 100
ax.annotate(f'改善 {improvement:.1f}%', 
            xy=(iterations[-1], costs[-1]), xytext=(iterations[-1]*0.6, costs[-1]*1.05),
            fontsize=11, color='#27AE60', fontweight='bold',
            arrowprops=dict(arrowstyle='->', color='#27AE60'))

ax.set_xlabel('迭代次数', fontsize=12)
ax.set_ylabel('总费用 (万元)', fontsize=12)
ax.set_title('图7  模拟退火收敛曲线', fontsize=14)
ax.legend(fontsize=11)
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('figures/图7_收敛曲线.png', dpi=300, bbox_inches='tight')
plt.savefig('figures/图7_收敛曲线.pdf', bbox_inches='tight')
```

### 视觉要求

- 曲线用深色（#2C3E50），线宽1.5pt
- 初始解用红点标注，最优解用绿点标注
- 标注改善百分比（如"改善 8.3%"）
- Y轴单位为万元（原始数据除以10000），避免数字过长
- 如果有多次重启，可以画多条浅色曲线+一条最优的深色曲线

        startangle=90, textprops={'fontsize': 10})

fig.suptitle(f'图8  总费用构成分析（总计 {C_total/10000:.2f} 万元）', fontsize=14, y=1.02)
