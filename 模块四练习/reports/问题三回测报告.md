# 问题三回测报告：方案D与方案E预测准确性对比

## 一、回测设计

### 1.1 目的

在相同条件下对比方案D（池化OLS回归）和方案E（偏差序列ARIMA）的预测准确性，以回测指标（而非满足率）作为模型选择依据。

### 1.2 数据划分

将240周数据划分为：

- 训练期：第1-216周（9个周期）
- 测试期：第217-240周（1个周期，24周）

测试期长度与问题三的实际预测任务（未来24周）完全一致。

### 1.3 评价对象

55家供应商在测试期内的所有有效观测（$O_{ij} > 0$ 的周次）。

## 二、方案D回测流程

### 2.1 训练

在训练期（1-216周）数据上：

- 计算每家供应商的 $F_1$-$F_4$（仅用1-216周数据）。
- 池化所有供应商训练期有效周观测，拟合OLS：

$$S_{ij} = \beta_0 + \beta_1 O_{ij} + \beta_2 F_{1i} + \beta_3 F_{2i} + \beta_4 F_{3i} + \beta_5 F_{4i} + \varepsilon_{ij}$$

### 2.2 预测

对测试期（217-240周）每条有效观测，代入实际 $O_{ij}$ 和训练期计算的 $F_{1i}$-$F_{4i}$：

$$\hat{S}_{ij}^{D} = \hat{\beta}_0 + \hat{\beta}_1 O_{ij} + \hat{\beta}_2 F_{1i} + \hat{\beta}_3 F_{2i} + \hat{\beta}_4 F_{3i} + \hat{\beta}_5 F_{4i}$$

### 2.3 注意

$F$ 值必须用训练期（1-216周）计算，不能用全量240周，否则存在数据泄露。

## 三、方案E回测流程

### 3.1 训练

对每家供应商，用训练期（1-216周）的有效周构建偏差序列：

$$D_{ij} = S_{ij} - O_{ij}, \quad j \in W_i \cap \{1, \dots, 216\}$$

执行ADF检验、Ljung-Box检验、ARIMA选阶（与正式建模流程一致）。

### 3.2 预测

对测试期24周，外推偏差预测值 $\hat{D}_{i,1}, \dots, \hat{D}_{i,24}$。

对测试期中实际有订货的周次（$O_{ij} > 0$），计算：

$$\hat{S}_{ij}^{E} = O_{ij} + \hat{D}_{ij}$$

截断非负：$\hat{S}_{ij}^{E} = \max(0, \hat{S}_{ij}^{E})$。

### 3.3 注意

ARIMA外推24步时，若供应商在训练期内有效周不连续（存在未订货间隔），偏差序列按有效周顺序排列，外推的24步对应"未来24个有效周"。需将预测值对齐到测试期的实际有效周上。

## 四、准确性评价指标

### 4.1 逐观测指标（所有供应商×测试期有效周）

设测试期有效观测总数为 $n$，真实值为 $S_{ij}$，预测值为 $\hat{S}_{ij}$。

**均方根误差：**

$$\text{RMSE} = \sqrt{\frac{1}{n}\sum(S_{ij} - \hat{S}_{ij})^2}$$

**平均绝对误差：**

$$\text{MAE} = \frac{1}{n}\sum|S_{ij} - \hat{S}_{ij}|$$

**平均绝对百分比误差：**

$$\text{MAPE} = \frac{1}{n}\sum\frac{|S_{ij} - \hat{S}_{ij}|}{S_{ij}} \times 100\%$$

注：$S_{ij} = 0$ 的观测不参与MAPE计算（分母为零）。

**测试集 $R^2$：**

$$R^2_{\text{test}} = 1 - \frac{\sum(S_{ij} - \hat{S}_{ij})^2}{\sum(S_{ij} - \bar{S})^2}$$

其中 $\bar{S}$ 为测试期真实值均值。

### 4.2 周总量指标（24个周）

每周真实总供货量（产品体积）：$T_j = \sum_i S_{ij} / u_i$

每周预测总供货量：$\hat{T}_j = \sum_i \hat{S}_{ij} / u_i$

**周总量RMSE：**

$$\text{RMSE}_{\text{week}} = \sqrt{\frac{1}{24}\sum_{j=217}^{240}(T_j - \hat{T}_j)^2}$$

**周总量MAPE：**

$$\text{MAPE}_{\text{week}} = \frac{1}{24}\sum_{j=217}^{240}\frac{|T_j - \hat{T}_j|}{T_j} \times 100\%$$

### 4.3 达标判断一致性

测试期24周中，真实达标的周集合 $\mathcal{A} = \{j : T_j \geq 28200\}$，模型预测达标的周集合 $\hat{\mathcal{A}} = \{j : \hat{T}_j \geq 28200\}$。

**分类准确率：**

$$\text{Acc} = \frac{|\mathcal{A} \cap \hat{\mathcal{A}}| + |\mathcal{A}^c \cap \hat{\mathcal{A}}^c|}{24}$$

即模型正确判断"达标/不达标"的周数占比。

## 五、输出物

- `results/problem3_backtest_metrics.csv`：两方案的RMSE、MAE、MAPE、$R^2_{\text{test}}$（逐观测）和RMSE_week、MAPE_week（周总量）。
- `results/problem3_backtest_weekly.csv`：测试期24周的 $T_j$、$\hat{T}_j^D$、$\hat{T}_j^E$、真实达标/预测达标。
- `results/problem3_backtest_classification.csv`：达标判断准确率。
- `figures/problem3_backtest_scatter.png`：预测值vs真实值散点图（D和E各一张，标注y=x参考线）。
- `figures/problem3_backtest_weekly.png`：测试期24周真实总量 vs D预测 vs E预测折线图。
- 控制台输出：汇总指标表格，直接用于建模手判断。

## 六、判断标准

- 若D的RMSE和MAE均低于E（至少低5%以上），选D。
- 若E的RMSE和MAE均低于D，选E。
- 若两者差距<5%，视为等价，选模型更简洁/业务语义更自然的那个。
- 周总量指标和达标判断准确率作为辅助参考。
