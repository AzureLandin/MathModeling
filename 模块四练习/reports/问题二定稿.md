# 问题二定稿：最优原材料订购方案（0-1整数规划）

## 一、问题定位

针对问题一筛选出的55家供应商，制定未来24周每周的原材料订购方案。核心决策为：每一周向哪些供应商下单（0-1选择），使得在满足产能需求与订购频次约束的前提下，采购总成本最小。

## 二、参数定义

**决策变量：**

$$x_{ij} \in \{0, 1\}, \quad i = 1, 2, \dots, 55;\; j = 1, 2, \dots, 24$$

$x_{ij} = 1$ 表示第 $j$ 周向第 $i$ 家供应商订货，否则为0。

**已知参数（由历史数据确定）：**

- $Q_i$：第 $i$ 家供应商的固定订货量，取其过去240周的周均订货量四舍五入取整，即 $Q_i = \text{round}\!\left(\frac{1}{N_i}\sum_{j \in W_i} O_{ij}\right)$。
- $F_i$：第 $i$ 家供应商在24周计划期内的最低订货次数。取过去240周（10个周期）的总订货次数除以10后向上取整：$F_i = \lceil \frac{1}{10} \sum_{j=1}^{240} I(O_{ij} > 0) \rceil$。
- $u_i$：第 $i$ 家供应商所供材料类型的单位产品原材料消耗率。A类 $u=0.6$，B类 $u=0.66$，C类 $u=0.72$（单位：m³原材料/m³产品）。
- $p_i$：第 $i$ 家供应商所供材料的相对采购单价（以C类为基准1）。A类 $p=1.2$，B类 $p=1.1$，C类 $p=1.0$。

### 参数求解结果

| 参数    | 范围                  | 说明     |
| ----- | ------------------- | ------ |
| $Q_i$ | [1, 1261] m³        | 四舍五入取整 |
| $F_i$ | [4, 24] 次           | 向上取整   |
| 材料类型  | A=15家, B=17家, C=23家 | C类最多   |

## 三、目标函数

以最小化24周采购总成本为目标：

$$\min Z = \sum_{j=1}^{24} \sum_{i=1}^{55} p_i \cdot Q_i \cdot x_{ij}$$

### 成本结构分析

将单价与消耗率结合，定义单位产品成本系数 $c_i = p_i \cdot u_i$：

| 材料类型 | 单价 $p_i$ | 消耗率 $u_i$ | 单位产品成本 $c_i = p_i \cdot u_i$ |
|:----:|:--------:|:---------:|:----------------------------:|
| A    | 1.2      | 0.6       | 0.720                        |
| B    | 1.1      | 0.66      | 0.726                        |
| C    | 1.0      | 0.72      | 0.720                        |

A类与C类的单位产品成本精确相等（均为0.720），B类仅高出约0.83%。这意味着：

（1）成本目标对A类与C类供应商完全无差异。在A/C之间的选择不由成本驱动，而由产能约束和频次约束的组合可行性决定。

（2）对B类供应商存在极微弱的成本惩罚（0.83%），模型在可行解空间中会轻微倾向于少选B类，但该偏好几乎可忽略。

（3）由于A/C等价性，最优解在A类与C类供应商的排班组合上可能存在多解性（等价替换不改变目标值）。本文取求解器返回的第一个最优解。

## 四、约束条件

**约束一：周产能底线约束**

每周订购量折算为产品体积后，须至少达到周产能28200 m³的90%（即25380 m³）：

$$\sum_{i=1}^{55} \frac{Q_i}{u_i} \cdot x_{ij} \geq 25380, \quad \forall\, j \in \{1, 2, \dots, 24\}$$

其中 $Q_i / u_i$ 将原材料体积转换为可生产的产品体积。

**约束二：最低订购频次约束**

在24周计划期内，每家供应商的被选中次数不低于其历史平均周期订货次数：

$$\sum_{j=1}^{24} x_{ij} \geq F_i, \quad \forall\, i \in \{1, 2, \dots, 55\}$$

**约束三：变量类型约束**

$$x_{ij} \in \{0, 1\}, \quad \forall\, i, j$$

## 五、模型性质与求解

**模型规模：** 55×24 = 1320个0-1决策变量，24个产能约束 + 55个频次约束 = 79个线性约束。属于中小规模0-1整数线性规划（BILP），采用分支定界法精确求解（PuLP + CBC求解器）。

### 求解结果

| 指标            | 数值            |
| ------------- | ------------- |
| 求解状态          | Optimal（全局最优） |
| 最优目标值（24周总成本） | 445,935.30    |
| 求解时间          | 秒级            |

### 建模解读

模型在秒级内返回全局最优解，表明问题规模适中、约束结构良好。最优目标值445,935对应24周平均每周成本约18,580，各周成本在18,327-18,822之间波动（差异约2.7%），波动来源为不同周次选中的供应商组合略有不同。

## 六、方案分析

### 6.1 产能满足情况

| 指标            | 数值          |
| ------------- | ----------- |
| 平均周订购量（产品体积）  | 25,733 m³   |
| 最小周订购量        | 25,381 m³   |
| 最大周订购量        | 26,067 m³   |
| 达标周数（≥25,380） | 24/24（100%） |
| 平均每周选中供应商数    | 46.8家       |

### 建模解读

所有24周均满足90%产能底线要求，最低周为25,381 m³（仅超底线1 m³），表明最优解紧贴约束边界——这是成本最小化目标下的必然行为：模型在满足约束的前提下尽可能减少订购量以降低成本。

55家供应商全选时的周产能为26,176 m³，仅为底线要求的103.1%，产能余量极薄（796 m³）。这意味着问题二本质上不是一个"从55家中宽裕地挑选子集"的问题，而是一个"每周仅能少用少数几家"的紧约束调度问题。平均每周选中46.8家（仅8家轮休），优化空间主要体现在频次约束与成本微差的权衡上，而非大幅度的供应商取舍。

### 6.2 材料类型分布

每周供应商类型分布：A类10-14家、B类13-17家、C类16-23家。三类材料每周均有充分覆盖，不存在类型偏倚，无需额外施加材料配比约束。

### 6.3 频次约束结构

频次约束总和 $\sum_i F_i = 1081$，上限为 $55 \times 24 = 1320$，平均每家供应商被要求订货约19.6次/24周。部分供应商 $F_i = 24$（每周必须订购），属于"铁打不动"的必选供应商；真正具有调度弹性的为 $F_i$ 较小的供应商，模型通过调节这些供应商的排班实现成本微优化。

## 七、对问题三的衔接

订购方案确定了每周向哪些供应商下单及固定订货量 $Q_i$，问题三需在此基础上，根据供应商的历史供货特征推算实际到货量。需注意：产能余量仅3.1%，而供应商实际供货存在向下波动（历史供货率并非100%），因此实际产能满足率预计将进一步低于订购阶段的90%保障水平。
