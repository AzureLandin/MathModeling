# 问题一建模报告：基于CRITIC-TOPSIS的供应商重要性评价模型

## Part A：方法论

### 1. 问题定位

对402家历史供应商进行综合量化评价，筛选出排名前55的最重要供应商，为问题二的订购方案制定提供决策基础。"重要性"的操作化定义为：在保障企业连续生产方面，该供应商的供货贡献与供货可靠性的综合表现。

### 2. 基础变量与数据预处理

设 $O_{ij}$ 为第 $i$ 家供应商第 $j$ 周的订货量，$S_{ij}$ 为对应的实际供货量（$i = 1, 2, \dots, 402$；$j = 1, 2, \dots, 240$）。

定义第 $i$ 家供应商的有效订货周集合：

$$W_i = \{j \mid O_{ij} > 0\}$$

其有效周数记为 $N_i = |W_i|$。

预处理说明：仅在被实际订货的周次上提取统计特征，规避未发生业务往来的周次（$O_{ij}=0$）对均值、方差等统计量的稀释干扰。

### 3. 特征指标体系

针对第 $i$ 家供应商，从四个维度提取评价指标：

**指标 $F_1$：周均供货量（极大型）**

衡量剔除未订货干扰后的平均周产能贡献，反映供应商的供货规模。

$$F_{1i} = \frac{1}{N_i} \sum_{j \in W_i} S_{ij}$$

**指标 $F_2$：周均供货缺失量（极小型）**

衡量未按要求履约的平均缺口。引入截断函数 $\max(\cdot, 0)$ 仅统计缺货方向的差值，防止超额供货的冗余量抵消缺货量：

$$F_{2i} = \frac{1}{N_i} \sum_{j \in W_i} \max(0,\; O_{ij} - S_{ij})$$

**指标 $F_3$：供货达标率（极大型）**

衡量足额或超额保障产能的频次占比，反映连续稳定供货能力。设 $I(\cdot)$ 为指示函数：

$$F_{3i} = \frac{1}{N_i} \sum_{j \in W_i} I(S_{ij} \geq O_{ij})$$

注：采用 $\geq$（含等号），使得精确交货（$S=O$）计入达标，度量的是"履约可靠性"而非"超额供货倾向"。

**指标 $F_4$：供货偏差均方（极小型）**

衡量供货偏差的离散程度，反映供货波动的剧烈程度：

$$F_{4i} = \frac{1}{N_i} \sum_{j \in W_i} (O_{ij} - S_{ij})^2$$

指标互补性说明：$F_2$ 捕捉方向性偏差（单侧缺货缺口的均值），$F_4$ 在此基础上进一步捕捉无方向的波动幅度（含超额供货的偏差）。二者存在相关性但侧重不同，CRITIC法将通过指标间相关性结构自动调节冗余权重。

### 4. CRITIC客观赋权（主模型）

构建原始特征矩阵 $X = (x_{ik})_{402 \times 4}$，其中 $k = 1, 2, 3, 4$ 对应 $F_1, F_2, F_3, F_4$。

**步骤一：数据正向化与标准化**

对极大型指标（$F_1, F_3$）：

$$y_{ik} = \frac{x_{ik} - \min_i(x_{ik})}{\max_i(x_{ik}) - \min_i(x_{ik})}$$

对极小型指标（$F_2, F_4$）：

$$y_{ik} = \frac{\max_i(x_{ik}) - x_{ik}}{\max_i(x_{ik}) - \min_i(x_{ik})}$$

**步骤二：计算对比强度**

对标准化矩阵 $Y = (y_{ik})_{402 \times 4}$，计算第 $k$ 项指标的标准差作为对比强度：

$$\sigma_k = \sqrt{\frac{1}{402-1} \sum_{i=1}^{402} (y_{ik} - \bar{y}_k)^2}$$

$\sigma_k$ 越大，说明该指标在供应商间的区分能力越强。

**步骤三：计算指标冲突性**

计算指标间Pearson相关系数矩阵 $R = (r_{jk})_{4 \times 4}$，第 $k$ 项指标的冲突性为：

$$\gamma_k = \sum_{j=1}^{4} (1 - r_{jk})$$

$r_{jk}$ 越接近1，两指标信息越冗余，冲突性越小；$r_{jk}$ 越接近0或为负，独立信息越多，冲突性越大。

**步骤四：计算综合权重**

第 $k$ 项指标的信息承载量为对比强度与冲突性的乘积：

$$I_k = \sigma_k \cdot \gamma_k$$

归一化得权重：

$$w_k = \frac{I_k}{\sum_{k=1}^{4} I_k}$$

**选取CRITIC而非熵权法的理由：**

熵权法仅依据指标的离散程度（信息熵）分配权重，本质上度量的是"哪个指标在供应商间差异最大"。在本问题中，$F_1$（周均供货量）的原始值域跨度极大（个位数至1500+），而 $F_2$、$F_4$ 对多数供应商集中在0附近，导致熵权法将93%的权重集中于 $F_1$，评价体系退化为单指标排序。

CRITIC在对比强度之外引入冲突性维度，能够识别并奖励与其他指标独立性强的指标。$F_3$（供货达标率）与 $F_1$ 相关性低——供应商可以量大但不稳定，也可以量中等但从不断供——这种"不可替代的信息维度"恰好是保障生产连续性的关键判据。CRITIC赋予 $F_3$ 最高权重（0.53），更贴合"保障企业生产重要性"的业务语义。

### 5. TOPSIS综合排序

利用CRITIC权重 $w_k$ 构建加权标准化矩阵 $Z = (z_{ik})_{402 \times 4}$：

$$z_{ik} = w_k \cdot y_{ik}$$

确定正理想解与负理想解：

$$Z_k^+ = \max_i(z_{ik}), \quad Z_k^- = \min_i(z_{ik})$$

计算各供应商到正、负理想解的欧氏距离：

$$D_i^+ = \sqrt{\sum_{k=1}^{4} (z_{ik} - Z_k^+)^2}$$

$$D_i^- = \sqrt{\sum_{k=1}^{4} (z_{ik} - Z_k^-)^2}$$

计算相对贴近度：

$$C_i = \frac{D_i^-}{D_i^+ + D_i^-}$$

依据 $C_i$ 对402家供应商降序排列，取前55名作为问题二的供应商集合。

### 6. 熵权-TOPSIS稳健性验证（辅助模型）

为验证评价结论对赋权方法不敏感，以熵权法作为替代赋权方案进行交叉验证。

**熵权法赋权：**

在标准化矩阵 $Y$ 上（平移 $\varepsilon = 0.0001$ 防止对数无意义），计算第 $k$ 项指标的特征比重与信息熵：

$$p_{ik} = \frac{y_{ik}}{\sum_{i=1}^{402} y_{ik}}, \quad E_k = -\frac{1}{\ln 402} \sum_{i=1}^{402} p_{ik} \ln(p_{ik})$$

约定 $p_{ik} = 0$ 时 $p_{ik} \ln(p_{ik}) = 0$。权重为：

$$w_k^{E} = \frac{1 - E_k}{\sum_{k=1}^{4} (1 - E_k)}$$

以 $w_k^E$ 替代CRITIC权重，重复TOPSIS流程，得到熵权法下的排名。

**一致性检验：**

设CRITIC-TOPSIS的前55名集合为 $\mathcal{S}_C$，熵权-TOPSIS的前55名集合为 $\mathcal{S}_E$，计算：

- 重合率：$|\mathcal{S}_C \cap \mathcal{S}_E| / 55$
- Spearman秩相关系数 $\rho$：对402家供应商在两种方法下的排名计算

若重合率 $\geq 80\%$ 且 $\rho \geq 0.95$，则认为评价结果对赋权方法不敏感，CRITIC-TOPSIS的筛选结论具有稳健性。

## Part B：编程实现指引

### 数据读取

- 读取附件1两个sheet（"企业的订货量"和"供应商的供货量"），各409行（含表头+402供应商+可能的空行）×242列（供应商ID + 材料分类 + 240周）。
- 注意检查是否存在全行为0的供应商（从未被订过货），若有则 $N_i = 0$，需排除或特殊处理。

### 指标计算边界条件

- $F_3$ 中 $I(S_{ij} \geq O_{ij})$：当 $O_{ij} > 0$ 且 $S_{ij} \geq O_{ij}$ 时取1，含精确相等的情况。
- $F_4$ 计算的是 $(O-S)^2$ 而非 $(S-O)^2$，数值相同但语义上强调"订货与供货的偏差"。
- 若某供应商 $N_i$ 极小（如仅1-2周），其统计量不稳定，可考虑设置最低有效周数阈值（如 $N_i \geq 5$），低于阈值的供应商直接排除。

### CRITIC实现注意事项

- CRITIC在min-max标准化矩阵 $Y$ 上计算，不要对 $Y$ 再做Z-Score（否则所有 $\sigma_k = 1$，对比强度维度退化）。
- 相关系数矩阵用 `numpy.corrcoef(Y, rowvar=False)`，输入402×4，输出4×4。
- 标准差用 `numpy.std(Y, axis=0, ddof=1)`（样本标准差）。
- 若某指标所有供应商取值相同（$\max = \min$），标准化分母为0，需特判。

### 熵权法数值注意事项

- 平移 $\varepsilon$ 后直接计算比重即可，不影响排序。
- 约定 $0 \ln 0 = 0$。

### TOPSIS实现

- 加权标准化矩阵直接在标准化矩阵上逐列乘以 $w_k$。
- 最终输出：55家供应商的ID、材料类别、贴近度得分，供问题二使用。

### 输出物

- `results/problem1_supplier_ranking.csv`：402家供应商完整排名（ID、类别、四指标值、CRITIC权重、贴近度、排名）。
- `results/problem1_top55.csv`：前55家供应商子集。
- `results/problem1_critic_weights.csv`：CRITIC四指标权重及中间量（$\sigma_k$、$\gamma_k$、$I_k$）。
- `results/problem1_entropy_weights.csv`：熵权法四指标权重（辅助验证用）。
- `results/problem1_robustness_comparison.csv`：两种方法排名对比（ID、CRITIC排名、熵权排名、排名差）。
- `figures/problem1_weight_comparison.png`：两种方法权重对比柱状图。
- `figures/problem1_score_distribution.png`：贴近度分布直方图（标注第55名分位线）。
- `figures/problem1_rank_scatter.png`：排名散点图（x=CRITIC排名，y=熵权排名），标注前55名分界线。
- 控制台输出：重合率、Spearman ρ及p值。
