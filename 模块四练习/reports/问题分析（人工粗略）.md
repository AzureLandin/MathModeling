# 问题一的分析

此问题是一个评价类问题，所以我们考虑使用评价模型，如层次分析，熵权法，TOPSIS等；由于题目没有直接给出待考察的特征，所以需要进行特征工程，自行设计特征；

一般来说，供货商的评价可以从以下方面来考察（引参考文献），

### 供货质量和稳定性（能否按量稳定供货）

周供货量均值

将240周的总实际供货量相加，除以有效订货的周数（剔除未订货的干扰）。

### 及时到货程度与企业信用度

周供货缺失量均值

计算240周内所有“订货量减去实际供货量”的差值总和，再除以有效订货周数。该值反映了供应商平均每周未按要求履约的缺货数量。

### 连续稳定供货的能力（满足并超越需求的能力）

供货率

计算出现供货达标并超额达成（即供货量大于订货量）的周数，在所有有效订货周数中所占的比例

### 供货的可靠性

供货量均方差

计算每一周“订货量与实际供货量之差”的平方和，反映供货偏差的离散程度（波动越大，可靠性越低）

此题我们可以采用CRITIC+TOPSIS来确定较优方案

# 问题二的分析

最优订购方案应该满足一下几个条件：要优先保证产能足够、采购成本最小化、供货稳定度高

### 产能足够

要求每周的订货量能保证达到产能的百分之90以上

由于每立方米产品消耗 A、B、C 类材料的体积不同（分别为 **0.6**、**0.66**、**0.72** 立方米），最优的供货方案在折算后，应当使得“达到周产能需求的比例”尽可能接近 **100%**。

### 采购成本最小化

在满足产能需求的前提上，要尽可能的最小化采购成本

题目明确给出了价格差异：A 类和 B 类原材料的采购单价分别比 C 类高 **20%** 和 **10%**。

假设 C 类材料单价为常数 1，则 A、B 单价对应为 1.2 和 1.1。最优方案应当在供需匹配的前提下，在结构上尽可能向 C 类材料倾斜，压缩 A 类材料的份额，从而使得总采购目标函数 $Cost = 1.2S_A + 1.1S_B + S_C$ 达到最小。

### 供货稳定度高

因为题目已有：“企业对供应商实际提供的原材料总是全部收购”

所以如果供应商总是超额供应，会导致企业原材料积压无法完全利用。

如果供货量低于订货量，会直接导致原材料断档、产能不达标

所以供货稳定度也是考虑的因素

每周对每个供应商来说只有两种状态，该周被订货和不被订货，所以这是一个0-1整数规划问题

# 问题三的分析

问题要求我们根据供货商的历史供货特征来给供货商制定一个供货方案，这是一个回归预测问题

我们注意到每一周的订货量可能会与这一周的下一周的供货量有关系，如果这一周的订货量变大，对供货商的供货能力的占用就会提，所以下一周的供货量就会相对降低；反之、如果这一周的订货量变小，对供货商的供货能力的占用就会减小，所以下一周的供货量会相对提高

此外，订货量规定了供货量的量级，供货商不可能无止境的超额供货，也不可能直接不供货，供货量一定在订货量附近，这是订货量的锚定作用。

所以我们对于供货量的预测一定要嵌入订货量的信息。

综上，我们计划采用时间序列模型ARIMA来对每周订货量和实际供货量的差值进行预测
