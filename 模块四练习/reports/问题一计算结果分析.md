# 问题一计算结果分析：基于CRITIC-TOPSIS的供应商重要性评价

## 1. CRITIC权重分析（主模型）

| 指标           | CRITIC权重   | 对比强度σ  | 冲突性γ   | 信息承载量I |
| ------------ | ---------- | ------ | ------ | ------ |
| F1 周均供货量     | 0.2847     | 0.1213 | 3.4661 | 0.4205 |
| F2 周均缺失量     | 0.0922     | 0.0564 | 2.4139 | 0.1361 |
| **F3 供货达标率** | **0.5325** | 0.2927 | 2.6872 | 0.7865 |
| F4 供货偏差均方    | 0.0907     | 0.0533 | 2.5144 | 0.1339 |

**分析：**

- **F3（供货达标率）权重最高（0.53）**，原因是：
  - 对比强度σ=0.293（最大），说明各供应商在达标率上差异显著
  - 冲突性γ=2.69，说明F3与其他指标的信息独立性强
- F1（周均供货量）权重0.28，位居第二
- F2、F4权重相近（约0.09），说明缺货量和波动幅度的信息冗余度较高

**与熵权法的差异：**

- 熵权法将93%权重集中于F1，退化为单指标排序
- CRITIC通过冲突性维度识别出F3的"不可替代信息"，赋权更合理
- F3（供货达标率）度量的是"履约可靠性"，更贴合"保障企业生产重要性"的业务语义

- 供货量大但不稳定的供应商排名下降
- 这更符合"保障企业连续生产"的题意

## 3. 稳健性验证（熵权-TOPSIS对比）

| 验证指标       | 数值         | 判定标准      | 结论  |
| ---------- | ---------- | --------- | --- |
| 前55名重合数    | **46/55**  | ≥44 (80%) | 通过  |
| 重合率        | **83.6%**  | ≥80%      | 通过  |
| Spearman ρ | **0.9909** | ≥0.95     | 通过  |

**结论：** 尽管两种赋权方法的权重分布差异显著，但最终排名高度一致（ρ=0.99），说明CRITIC-TOPSIS的评价结果具有稳健性。
