# C题 问题一：银行信用评级准确性验证 —— 建模报告

## 一、问题分析

问题一要求：根据附件1中123家有信贷记录企业的交易票据数据，验证银行给出的信用等级（A/B/C/D）分类结果是否准确。

验证逻辑：将银行评级暂定为基准标签，基于企业交易数据构造客观特征，建立分类模型反推评级，通过模型预测结果与银行原标签的一致性程度来评判评级准确性。若一致性高，说明银行评级客观可靠；若大量错位，说明原评级存在主观偏差或错配。

解题路线：原始发票流水 → 企业级特征聚合 → 异常值处理与标准化 → PCA降维 → 多元Logit建模 → XGBoost辅助验证 → 一致性评估与稳健性检验。

## 二、特征工程

### 2.1 企业级汇总变量

对每家企业，将全部进项发票和销项发票按状态（有效/作废/负数）分类汇总，提取以下变量：

**进项侧：**

| 编号 | 变量名 | 定义 |
|------|--------|------|
| $x_1$ | 进项发票数量 | 全部进项发票条数 |
| $x_2$ | 进项有效发票数量 | 状态为"有效发票"的条数 |
| $x_3$ | 进项作废发票数量 | 状态为"作废发票"的条数 |
| $x_4$ | 进项负数发票数量 | 有效进项发票中价税合计 < 0 的条数（即退货退款冲抵发票） |
| $x_5$ | 进项有效金额 | 有效进项发票"金额"列求和 |
| $x_6$ | 进项有效税额 | 有效进项发票"税额"列求和 |
| $x_7$ | 进项无效额 | 作废进项发票"价税合计"求和取绝对值 |
| $x_8$ | 进项有效价税总和 | 有效进项发票"价税合计"求和 |

**销项侧（对称）：**

| 编号 | 变量名 | 定义 |
|------|--------|------|
| $x_9$ | 销项发票数量 | 全部销项发票条数 |
| $x_{10}$ | 销项有效发票数量 | 状态为"有效发票"的条数 |
| $x_{11}$ | 销项作废发票数量 | 状态为"作废发票"的条数 |
| $x_{12}$ | 销项负数发票数量 | 有效销项发票中价税合计 < 0 的条数（即退货退款冲抵发票） |
| $x_{13}$ | 销项有效金额 | 有效销项发票"金额"列求和 |
| $x_{14}$ | 销项有效税额 | 有效销项发票"税额"列求和 |
| $x_{15}$ | 销项无效额 | 作废销项发票"价税合计"求和取绝对值 |
| $x_{16}$ | 销项有效价税总和 | 有效销项发票"价税合计"求和 |

**衍生变量：**

| 编号 | 变量名 | 定义 | 业务含义 |
|------|--------|------|----------|
| $x_{17}$ | 有效收入 | $x_{16} - x_8$ | 企业净营收能力 |
| $x_{18}$ | 作废发票率 | $(x_3 + x_{11}) / (x_1 + x_9)$ | 交易取消频率，反映经营稳定性 |
| $x_{19}$ | 负数发票率 | $(x_4 + x_{12}) / (x_1 + x_9)$ | 退货退款频率，反映服务质量 |

> 注：数据中发票状态仅有"有效发票"和"作废发票"两种取值，不存在独立的"负数发票"状态。题目所述的"负数发票"是指有效发票中金额为负的条目（代表退货退款后的冲抵），需通过判断价税合计 < 0 来识别。

### 2.2 供应链稳定度特征（独立构造，不进PCA）

| 编号 | 变量名 | 定义 |
|------|--------|------|
| $F_7$ | 进稳定度 | 进项发票中发票数量排名前3的销方单位的发票总数 / 进项发票总数 $x_1$ |
| $F_8$ | 销稳定度 | 销项发票中发票数量排名前3的购方单位的发票总数 / 销项发票总数 $x_9$ |
| $F_9$ | 进销稳定度 | $\sqrt{(F_7^2 + F_8^2) / 2}$ |

业务含义：衡量企业供应链的集中程度。$F_7$ 反映对上游供应商的依赖程度，$F_8$ 反映对下游客户的依赖程度，$F_9$ 为两者的综合度量。集中度过高意味着依赖少数交易对手，经营风险较大；过低则可能意味着业务分散、缺乏稳定合作关系。

### 2.3 时序动态特征（独立构造，不进PCA）

| 编号 | 变量名 | 定义 |
|------|--------|------|
| $F_{10}$ | 平均营收增长率 | 按自然年汇总销项有效价税合计，计算同比增长率后取均值 |

$$F_{10} = \frac{1}{T-1}\sum_{t=1}^{T-1}\frac{R_{t+1} - R_t}{|R_t| + \epsilon}$$

其中 $R_t$ 为第 $t$ 年的销项有效价税合计，$\epsilon$ 为平滑项（防止除零）。

时间窗口说明：数据覆盖2017年1月至2020年2月，其中2017、2018、2019为完整年份，2020年仅含1-2月。仅使用完整年份计算同比增长率。

计算完成后需对 $F_{10}$ 进行合理截断，剔除极端异常值（如基期营收极小导致增长率爆炸的情况）。具体截断阈值由编程手根据数据分布确定。

业务含义：营收增长率反映企业的发展趋势。持续增长的企业信用风险较低，持续萎缩的企业则相反。此为原论文（赵星然等，2022）未涉及的创新特征。

### 2.4 稳定度与增长率不进PCA的理由

稳定度（$F_7, F_8, F_9$）和增长率（$F_{10}$）本身已是无量纲的比值/比率，与19个发票汇总变量在量纲和语义上差别较大。若混入PCA，会干扰因子的经济含义解释。因此采用"并列"策略：PCA仅对发票汇总变量降维，稳定度和增长率作为独立特征与PCA因子并列进入模型。

## 三、异常值处理与标准化

### 3.1 Winsorize缩尾处理

对所有连续变量，将低于1%分位数的值替换为1%分位数，高于99%分位数的值替换为99%分位数。目的是抑制极端值对PCA和回归的干扰，同时保留数据分布形态。

### 3.2 Z-score标准化

对参与PCA的发票汇总变量进行标准化：

$$z_i = \frac{x_i - \bar{x}}{s}$$

其中 $\bar{x}$ 为样本均值，$s$ 为样本标准差。标准化后各变量均值为0、标准差为1，消除量纲差异对PCA的影响。

稳定度和增长率本身为比值，量纲统一，不做Z-score标准化。

## 四、PCA主成分降维

### 4.1 适用性检验

PCA之前需验证变量间存在足够相关性：

- **KMO（Kaiser-Meyer-Olkin）检验**：衡量偏相关系数相对于简单相关系数的大小。KMO > 0.5认为适合做因子分析。
- **Bartlett球形检验**：原假设为相关系数矩阵为单位阵（变量间无相关性）。若 $p < 0.05$ 则拒绝原假设，认为适合做因子分析。

### 4.2 主成分提取

1. 计算标准化后变量的相关系数矩阵及其特征值 $\lambda_1 \geq \lambda_2 \geq \cdots$。
2. 按**Kaiser准则**（特征根 > 1）确定公因子数目。
3. 计算累计方差贡献率，一般要求达到80%以上。
4. 对因子载荷矩阵进行**Varimax方差最大旋转**，使因子结构更清晰、更易解释。

### 4.3 因子命名

根据旋转后载荷矩阵，将高载荷变量归类，为每个公因子赋予经济含义命名。参照原论文，预期可能出现的因子类型：

| 因子类型 | 高载荷变量特征 | 业务含义 |
|----------|--------------|----------|
| 金额因子 | 有效金额、有效税额、有效价税总和类变量 | 企业资金规模与交易体量 |
| 活力因子 | 发票数量、有效发票数量类变量 | 企业交易活跃程度 |
| 故障因子 | 负数发票数量、负数发票率 | 退货退款风险 |
| 收入因子 | 有效收入 | 企业净盈利能力 |

> 注：实际提取的因子数目和命名取决于数据本身的结构，需根据实际载荷矩阵确定。具体结果由编程手核验后补充。

## 六、主模型：多元Logit模型

### 6.1 模型选择理由

多元Logit模型（Multinomial Logit Model）适用于因变量为多分类的情形，且对自变量无正态分布假设，适合本问题中特征分布偏斜的情况。同时，模型系数具有明确的经济含义，便于论文解释"哪些特征将企业推向更差的等级"。

### 6.2 模型设定

以A级为基准组（$y = A$），对其余各类别 $j \in \{B, C, D\}$ 建立对数机会比模型：

$$G_j = \ln\frac{P(y=j \mid \mathbf{x})}{P(y=A \mid \mathbf{x})} = \beta_{j0} + \sum_{k}\beta_{jk}x_k$$

其中 $\mathbf{x}$ 为入模特征向量，$\beta_{j0}$ 为截距项，$\beta_{jk}$ 为第 $k$ 个特征对第 $j$ 类别的回归系数。

基准组约束：$G_A = 0$，即 $\beta_{A0} = \beta_{Ak} = 0$。

### 6.3 预测概率

$$P(y=j \mid \mathbf{x}) = \frac{e^{G_j}}{\sum_{m \in \{A,B,C,D\}}e^{G_m}}$$

### 6.4 分类规则

取预测概率最大的类别为最终评级：

$$\hat{y} = \arg\max_{j} P(y=j \mid \mathbf{x})$$

### 6.5 系数解释

- $\beta_{jk} > 0$：特征 $x_k$ 增大时，企业被评为 $j$ 级（相对于A级）的对数机会比增大，即该特征将企业推向更差等级。
- $\beta_{jk} < 0$：该特征将企业推向更好等级。
- P值 < 0.05（或0.1）：该系数统计显著。

## 七、辅助验证：XGBoost

### 7.1 定位

XGBoost作为辅助验证模型，不承担主要建模任务，目的有二：

1. **准确率上界参照**：XGBoost为非参数模型，拟合能力强，其5折分层交叉验证准确率可视为"特征体系能达到的分类上限"。若XGBoost准确率也低，说明特征本身区分力不足；若XGBoost显著高于Logit，说明存在显著非线性关系，Logit的线性假设受限。
2. **特征重要性排序**：XGBoost输出的feature importance可佐证各因子的相对重要性，为论文分析提供支撑。

### 7.2 验证方式

采用5折分层交叉验证（Stratified K-Fold），确保每折中各评级类别的比例与总体一致。

## 八、评估指标体系

### 8.1 混淆矩阵

4×4矩阵，行为实际评级，列为预测评级。参照原论文表4格式，同时给出各级别样本数。

### 8.2 总体准确率

$$\text{Accuracy} = \frac{\text{对角线元素之和}}{N}$$

### 8.3 分级别准确率

$$\text{Acc}_j = \frac{\text{CM}_{jj}}{\text{第}j\text{行实际样本数}}$$

重点关注：D级准确率（模型能否有效甄别最差企业）、A级准确率（模型能否识别优质企业）、B/C级是否存在严重互相错配。

### 8.4 Cohen's Kappa系数

$$\kappa = \frac{p_o - p_e}{1 - p_e}$$

其中 $p_o$ 为观测一致率（即总体准确率），$p_e$ 为期望随机一致率。

解释标准：$\kappa < 0.4$ 一致性一般，$0.4 \leq \kappa < 0.6$ 中等，$0.6 \leq \kappa < 0.8$ 较好，$\kappa \geq 0.8$ 很好。

### 8.5 时效性稳健性检验

仅使用最近一年（2019年1月~2020年2月）的发票数据重新计算特征并训练模型，对比全数据与近期数据的准确率变化。

预期：近期数据准确率更高，说明交易信息具有时效性，离评级时点越近的数据对评级越有参考价值。此结论与相关部门对企业评级信息规范（有效期三年、每年复查一次）相吻合。

## 九、结论框架

根据模型结果，从以下角度给出结论：

1. **总体判断**：银行原始评级是否准确（以总体准确率和Kappa系数为依据）。
2. **分级别分析**：哪些级别评级准确，哪些存在错配（重点关注B/C级互相错配现象）。
3. **模型解释**：哪些特征对评级影响显著（以Logit系数显著性和XGBoost特征重要性为依据）。
4. **时效性结论**：近期数据是否比全期数据更能反映企业信用状况。
5. **建议**：对银行评级体系的改进建议（如对中间级别引入更细化的评估标准）。

| 维度 | 原论文 | 本研究 |

1. 引入供应链稳定度特征，刻画企业经营风险。

4. 增加时效性稳健性检验，验证数据时效性假设。
